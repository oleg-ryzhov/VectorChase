# Design conventions

## Units (SI everywhere)
- Mass: kg, distance: m, speed: m/s, angles: radians internally (degrees only in UI labels)
- Force: N, torque: N·m, power: kW in UI and W internally, friction: dimensionless μ

## Time
- Physics runs at a fixed step (1/120 s). Nothing in the simulation uses the raw frame delta.
- `timeScale` scales how much simulation time accumulates per frame. It never changes the step size.
- The UI and menus always run in real time. Race time and the countdown run on physics time.

## Parameters
- Every tunable value is defined once in `src/config/registry.js`.
- The physics reads every value once per fixed step through `readCarSpec()` in `src/physics/spec.js`,
  so a changed value applies on the next step. Registry values use UI units; `readCarSpec()` converts them.
- `subscribe(fn)` notifies listeners of real changes (the settings menu, the car model, the HUD).
- `tests/vehicle.test.mjs` runs random driving with all values at their minimum, maximum and alternating.

## Input
- Per-frame "pressed" events are read in `beforeFrame`, never inside the fixed update.
- `Input` ignores keys typed into text fields and leaves arrow keys and Space to sliders and buttons.

## Code rules
- Pure logic (time, registry, physics, track, race, bots, profiles, effects buffers) has no DOM or
  Three.js imports, so it can be tested in Node.

## Track and terrain
- The track is a closed Catmull-Rom curve (x, y height, z) defined in `src/track/trackData.js`.
- `buildTrack` resamples it at equal horizontal distances. Each point has distance `s`, position, unit
  tangent, right normal, signed curvature (positive = right turn) and grade. Heading is `atan2(tz, tx)`.
- `src/track/world.js` answers "how high is the ground at (x, z)", the surface grip there and the signed
  distance from the centre line. Beside the road the ground is flat for 14 m, then eases to natural terrain.
- The terrain mesh sits 0.1 m under the road so the two never flicker.

## Vehicle
- Planar four-wheel model in `src/physics/vehicle.js`. Body axes: u forward, v right, r yaw rate (positive = right).
- Each wheel has its own spin speed and inertia. Tire force comes from slip ratio and slip angle with a
  combined-slip curve scaled by friction and wheel load, including load transfer and downforce.
- Rear-wheel drive by default with an open differential. Drive and brake torque are capped just below the tire's
  grip limit (acts as traction control and ABS). The car samples the ground under all four wheels each step.
- Grass gives 55% grip and 4x rolling resistance. Gravity acts along the slope.
- `Vehicle.wheelSlip[i]` is how hard each tire works: 1 is peak grip, above 1 is sliding.

## Race, bots and collisions
- `TrackTracker` follows a car along the track (distance, laps, distance from the road). Progress stops counting
  more than 22 m from the centre line.
- `Race` runs the countdown, laps, finish and standings. The race ends when the player finishes.
- `BotDriver` returns analog pedals and steering. It reads `readCarSpec()` every step, so it adapts to the same
  settings the player changes. It keeps a safety margin, countersteers slides and lifts off while tires slide.
  Each difficulty has a cornering margin and a top speed.
- `src/physics/collisions.js` treats each car as three circles with impulse-based collisions (including spin).

## Players and scores
- Players are stored as plain readable JSON in `localStorage` (`src/profile/profiles.js`). There are no
  passwords and no encryption yet. Scores exist only on the device that played the race.
- All storage code takes the storage object as a parameter, so a server-backed version can replace it later.

## Effects and HUD
- `src/effects/` holds skid marks, smoke, dust and sparks. `ParticlePool` and `SkidBuffer` are pure logic.
- `src/ui/hud.js` shows speed, gear, rpm, a minimap and the settings that differ from their defaults.

function beforeFrame(frameDt) {
  // Read per-frame input here, never inside fixedUpdate.
  if (!isRacing() && settingsMenu.isOpen) settingsMenu.close();
  if (isRacing() && input.wasPressed('KeyE')) settingsMenu.toggle();
  if (isRacing() && !settingsMenu.isOpen && input.wasPressed('KeyC')) {
    cameraMode = cameraMode === 'first' ? 'chase' : 'first';
  }
  const driving = race !== null && race.phase === 'racing' && !settingsMenu.isOpen;
  if (driving && input.wasPressed('KeyR')) respawn(player);

  // The car is released while the settings menu is open.
  controls.forward = driving && (input.isDown('KeyW') || input.isDown('ArrowUp'));
  controls.back = driving && (input.isDown('KeyS') || input.isDown('ArrowDown'));
  controls.left = driving && (input.isDown('KeyA') || input.isDown('ArrowLeft'));
  controls.right = driving && (input.isDown('KeyD') || input.isDown('ArrowRight'));

  controls.handbrake = driving && input.isDown('Space');
  boostHeld = driving && (input.isDown('ShiftLeft') || input.isDown('ShiftRight'));

  // Time slows down while the settings menu is open and eases back afterwards.
  const target = settingsMenu.isOpen ? MENU_TIME_SCALE : 1;
  const diff = target - stepper.timeScale;
  stepper.timeScale =
    Math.abs(diff) < 0.001 ? target : stepper.timeScale + diff * (1 - Math.exp(-frameDt * TIME_EASE_RATE));
}

function fixedUpdate(dt) {
  if (race === null) return;
  if (race.phase === 'countdown') {
    race.update(dt);
    return;
  }
  if (race.phase !== 'racing') return;

  const spec = readCarSpec();
  controls.boost = style.boosting;
  for (const e of entrants) {
    e.car.step(dt, e.isPlayer ? controls : e.driver.drive(e.car, e.tracker, spec));
  }

  // A sudden loss of speed during collision handling is an impact: throw sparks.
  const before = entrants.map((e) => Math.hypot(e.car.u, e.car.v));
  resolveCollisions(
    entrants.map((e) => e.car),
    world,
    spec
  );
  let playerCrashed = false;
  entrants.forEach((e, i) => {
    const lost = before[i] - Math.hypot(e.car.u, e.car.v);
    if (e.isPlayer && lost > SPARK_SPEED_LOSS) playerCrashed = true;
    if (lost > SPARK_SPEED_LOSS) effects.spark(e.car.x, e.car.y + 0.5, e.car.z, Math.min(30, Math.round(lost * 3)));
  });

  style.update(dt, player.car, { boostHeld, crashed: playerCrashed });

  for (const e of entrants) {
    e.tracker.update(e.car.x, e.car.z);

    // Bots that get stuck or lost are put back on the road.
    if (!e.isPlayer) {
      e.stuckTime = e.car.u < 1.5 ? e.stuckTime + dt : 0;
      e.offRoadTime = e.tracker.offTrack ? e.offRoadTime + dt : 0;
      if (e.stuckTime > STUCK_SECONDS || e.offRoadTime > OFF_ROAD_SECONDS) respawn(e);
    }
  }
  race.update(dt);

  if (race.phase === 'finished' && !resultsShown) {
    resultsShown = true;
    finishRace();
  }
}

// Draws a car between its previous and current physics state and returns where it is.
function updateModel(e, alpha) {
  const c = e.car;
  const p = c.prev;
  const mix = (a, b) => a + (b - a) * alpha;
  const pose = { x: mix(p.x, c.x), y: mix(p.y, c.y), z: mix(p.z, c.z), yaw: mix(p.yaw, c.yaw) };
  e.model.update({
    ...pose,
    steer: mix(p.steer, c.steer),
    spin: c.wheelSpin.map((s, i) => mix(p.spin[i], s)),
    groundPitch: mix(p.pitch, c.pitch),
    groundRoll: mix(p.roll, c.roll),
    pitch: limitAngle(c.accelX * PITCH_PER_ACCEL),
    roll: limitAngle(-c.accelY * ROLL_PER_ACCEL),
    brake: c.brake,
  });
  return pose;
}

function render(alpha) {
  const now = performance.now();
  const frameDt = Math.min((now - lastRender) / 1000, 0.1);
  lastRender = now;

  let me = null;
  for (const e of entrants) {
    const pose = updateModel(e, alpha);
    if (e.isPlayer) me = pose;
  }

  const racing = isRacing();
  look.update(frameDt);
  view = racing ? cameraMode : 'orbit';
  if (racing && look.engaged) view = 'look';

  // Speed widens the field of view; the change is smoothed so it never pops.
  const speedFactor = Math.min(1, Math.abs(player.car.u) / FULL_SPEED);
  const targetFov =
    view === 'first'
      ? FIRST_PERSON_FOV + SPEED_FOV_BOOST * speedFactor
      : CHASE_FOV + (view === 'chase' ? SPEED_FOV_BOOST * speedFactor : 0);
  const nextFov = camera.fov + (targetFov - camera.fov) * (1 - Math.exp(-frameDt * 6));
  if (Math.abs(nextFov - camera.fov) > 0.005) {
    camera.fov = nextFov;
    camera.updateProjectionMatrix();
  }

  chaseYaw += (me.yaw - chaseYaw) * (1 - Math.exp(-frameDt * 4));
  chaseY += (me.y + CHASE_HEIGHT - chaseY) * (1 - Math.exp(-frameDt * 5));
  orbitAngle += frameDt * 0.35;

  if (view === 'first') {
    player.model.placeCamera(camera);
  } else if (view === 'chase') {
    const cx = Math.cos(chaseYaw);
    const cz = Math.sin(chaseYaw);
    const distance = CHASE_DISTANCE + 3 * speedFactor;
    const camX = me.x - cx * distance;
    const camZ = me.z - cz * distance;
    // Stay above the hill behind the car.
    camera.position.set(camX, Math.max(chaseY, world.groundHeight(camX, camZ) + 1.5), camZ);
    camera.lookAt(me.x + cx * 4, me.y + 1.0, me.z + cz * 4);
  } else if (view === 'look') {
    const pivot = { x: me.x, y: me.y + ROOF_PIVOT_HEIGHT, z: me.z };
    const p = look.position(pivot, me.yaw);
    camera.position.set(p.x, Math.max(p.y, world.groundHeight(p.x, p.z) + 0.8), p.z);
    camera.lookAt(pivot.x, pivot.y, pivot.z);
  } else {
    const camX = me.x + Math.cos(orbitAngle) * ORBIT_RADIUS;
    const camZ = me.z + Math.sin(orbitAngle) * ORBIT_RADIUS;
    camera.position.set(camX, Math.max(me.y + ORBIT_HEIGHT, world.groundHeight(camX, camZ) + 1.5), camZ);
    camera.lookAt(me.x, me.y + 0.8, me.z);
  }

  effects.update(frameDt, entrants, camera, renderer.domElement.height);
  renderer.render(scene, camera);

  hud.hidden = !racing;
  if (racing) hud.textContent =
      'W/S gas/brake · A/D steer · Space handbrake · Shift boost · drag mouse to look · C camera · R to road · E settings';

  hudPanel.setVisible(racing);
  if (racing) {
    hudPanel.update({
      kmh: Math.round(Math.abs(player.car.u) * 3.6),
      gear: player.car.gear < 0 ? 'R' : String(player.car.gear),
      rpm: player.car.rpm,
      redline: readCarSpec().redline,
      boost: style.meter,
      boosting: style.boosting,
      driftText:
        style.driftPoints > 0
          ? `DRIFT ${Math.round(style.driftPoints)} ×${style.multiplier}`
          : style.popup > 0
            ? style.popupText
            : '',
      cars: entrants.map((e) => ({ x: e.car.x, z: e.car.z, isPlayer: e.isPlayer, color: e.color })),
    });
  }

  if (race !== null) {
    raceUi.setStatus({
      position: race.standings().indexOf(player) + 1,
      total: entrants.length,
      lap: Math.min(race.laps, player.lapsDone + 1),
      laps: race.laps,
      time: Math.max(0, race.time),
      bestLap: player.bestLap,
      offTrack: race.phase === 'racing' && player.tracker.offTrack,
    });
    raceUi.setCountdown(
      race.phase === 'countdown' ? String(Math.ceil(race.countdown)) : race.phase === 'racing' && race.time < 1 ? 'GO!' : ''
    );
  }

  input.endFrame();
}

// Bot driver: aims at a point ahead on the racing line and plans its speed from upcoming corners.
// It reads the same car spec as the physics, so it adapts when the settings change.
// Pure logic: no DOM or Three.js imports.

const G = 9.81;

// grip: share of the tire's cornering limit the bot uses. brake: share of the braking limit.
// maxSpeed (m/s) keeps the bot where the car stays stable; above about 50 m/s the rear gets light.
export const DIFFICULTY = {
  easy: { grip: 0.42, brake: 0.4, maxSpeed: 38 },
  medium: { grip: 0.48, brake: 0.45, maxSpeed: 44 },
  hard: { grip: 0.5, brake: 0.45, maxSpeed: 48 },
};

function clamp(x, lo, hi) {
  return Math.min(hi, Math.max(lo, x));
}

export class BotDriver {
  // variation: about 0.95..1 per bot. laneOffset: metres to the right of the centre line.
  constructor({ difficulty = 'medium', variation = 1, laneOffset = 0 } = {}) {
    const d = DIFFICULTY[difficulty] ?? DIFFICULTY.medium;
    this.gripFactor = d.grip * variation;
    this.brakeFactor = d.brake * variation;
    this.maxSpeed = d.maxSpeed;
    this.laneOffset = laneOffset;
  }

  // car: Vehicle, tracker: TrackTracker, spec: readCarSpec(). Returns analog controls.
  drive(car, tracker, spec) {
    const { points, spacing } = tracker.track;
    const n = points.length;
    const speed = Math.max(car.u, 0);

    // Steering: pure pursuit towards a point ahead on the line.
    const lookAhead = clamp(8 + 0.5 * speed, 10, 40);
    const aim = points[(tracker.index + Math.round(lookAhead / spacing)) % n];
    const dx = aim.x + aim.nx * this.laneOffset - car.x;
    const dz = aim.z + aim.nz * this.laneOffset - car.z;
    const cosYaw = Math.cos(car.yaw);
    const sinYaw = Math.sin(car.yaw);
    const ahead = dx * cosYaw + dz * sinYaw;
    const right = -dx * sinYaw + dz * cosYaw;
    const alpha = Math.atan2(right, ahead);
    const distance = Math.max(Math.hypot(dx, dz), 1);
    const pursuitAngle = Math.atan((2 * spec.wheelbase * Math.sin(alpha)) / distance);
    // Countersteer: when the car slides, point the front wheels along the direction it is travelling.
    const slideAngle = speed > 5 ? Math.atan2(car.v, speed) : 0;
    const wheelAngle = pursuitAngle + slideAngle;
    const steerLimit = spec.maxSteer / (1 + (car.u / spec.steerSpeedRef) ** 2);
    const steer = clamp(wheelAngle / steerLimit, -1, 1);

    // Speed: the fastest speed from which every upcoming corner can still be taken.
    const cornerAccel = this.gripFactor * spec.friction * G;
    const brakeCapacity =
      (2 * (spec.frontBrakeTorque + spec.rearBrakeTorque)) / spec.wheelRadius / spec.mass;
    const brakeAccel = Math.min(this.brakeFactor * spec.friction * G, brakeCapacity * 0.9);
    const horizon = Math.min(300, (speed * speed) / (2 * brakeAccel) + 40);
    let target = this.maxSpeed;
    for (let d = 0; d <= horizon; d += 2 * spacing) {
      const p = points[(tracker.index + Math.round(d / spacing)) % n];
      const cornerSpeed = Math.min(this.maxSpeed, Math.sqrt(cornerAccel / Math.max(Math.abs(p.curvature), 1e-4)));
      target = Math.min(target, Math.sqrt(cornerSpeed * cornerSpeed + 2 * brakeAccel * d));
    }

    const error = target - speed;
    let throttle = 0;
    let brake = 0;
    if (error > 0) throttle = clamp(error / 3, 0, 1);
    else if (error < -1) brake = clamp((-error - 1) / 4, 0, 1);

    // Lift off the throttle while any tire is sliding, so the car can settle.
    const w = car.wheelSlip;
    if (Math.max(w[0], w[1], w[2], w[3]) > 1.05) throttle = 0;

    return { analog: true, throttle, brake, steer };
  }
}

// Free-look orbit around the car, driven by holding the mouse button and dragging.
// Pure logic: no DOM or Three.js imports.

const DEFAULT_PITCH = 0.25;

export class FreeLook {
  constructor() {
    this.yaw = 0; // 0 = straight behind the car
    this.pitch = DEFAULT_PITCH;
    this.radius = 7;
    this.active = false; // the button is held
    this.engaged = false; // active, or still easing back to the normal camera
  }

  start() {
    this.active = true;
    this.engaged = true;
  }

  end() {
    this.active = false;
  }

  drag(dx, dy) {
    if (!this.active) return;
    this.yaw -= dx * 0.006;
    this.pitch = Math.min(1.4, Math.max(-0.1, this.pitch + dy * 0.005));
  }

  zoom(amount) {
    this.radius = Math.min(16, Math.max(4, this.radius + amount * 0.01));
  }

  // Eases back to the normal camera after the button is released.
  update(dt) {
    if (this.active || !this.engaged) return;
    const k = Math.exp(-dt * 3);
    this.yaw *= k;
    this.pitch = DEFAULT_PITCH + (this.pitch - DEFAULT_PITCH) * k;
    if (Math.abs(this.yaw) < 0.02 && Math.abs(this.pitch - DEFAULT_PITCH) < 0.02) {
      this.yaw = 0;
      this.pitch = DEFAULT_PITCH;
      this.engaged = false;
    }
  }

  // Camera position around a pivot for a car heading carYaw.
  position(pivot, carYaw) {
    const a = carYaw + Math.PI + this.yaw;
    const c = Math.cos(this.pitch);
    return {
      x: pivot.x + this.radius * c * Math.cos(a),
      y: pivot.y + this.radius * Math.sin(this.pitch),
      z: pivot.z + this.radius * c * Math.sin(a),
    };
  }
}

import * as THREE from 'three';
import { readCarSpec, TRACK } from '../physics/spec.js';

const BODY_PIVOT_Y = 0.5; // body pitches and rolls about this height
const TIRE_WIDTH = 0.26;
const RIM_RADIUS = 0.22;
const ARCH_RADIUS = 0.42;
const SILL_Y = 0.2;
// Dimensions the body and wheel meshes are modelled at. Live values scale from these.
const MODEL_WHEEL_RADIUS = 0.33;
const MODEL_FRONT_AXLE_X = 1.3;
const MODEL_REAR_AXLE_X = -1.4;
const EYE = { x: 0.1, y: 1.15, z: -0.38 }; // driver's eye, left-hand drive
const STEERING_WHEEL_RATIO = 8;
const CENTER_HALF_WIDTH = 0.58;
const BODY_HALF_WIDTH = 0.925;

const glass = new THREE.MeshStandardMaterial({ color: 0x0d1720, metalness: 0.2, roughness: 0.08 });
const dark = new THREE.MeshStandardMaterial({ color: 0x15171c, metalness: 0.3, roughness: 0.7 });
const rubber = new THREE.MeshStandardMaterial({ color: 0x0e0e10, roughness: 0.95, side: THREE.DoubleSide });
const alloy = new THREE.MeshStandardMaterial({
  color: 0xc9ced6,
  metalness: 0.8,
  roughness: 0.3,
  side: THREE.DoubleSide,
});
const brakeDisc = new THREE.MeshStandardMaterial({ color: 0x6b6f76, metalness: 0.8, roughness: 0.5 });
const headlightMat = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  emissive: 0xfff2cc,
  emissiveIntensity: 1.2,
});
const marker = new THREE.MeshBasicMaterial({ color: 0xffd166 });

function polygon(points) {
  const shape = new THREE.Shape();
  points.forEach(([x, y], i) => (i === 0 ? shape.moveTo(x, y) : shape.lineTo(x, y)));
  shape.closePath();
  return shape;
}

// Extrudes a side profile (x forward, y up) across the car's width, centred on z = 0.
// Several bevel segments round the edges so the body looks smooth rather than faceted.
function extrude(shape, depth, material, bevel = 0.03) {
  const geometry = new THREE.ExtrudeGeometry(shape, {
    depth,
    bevelEnabled: true,
    bevelThickness: bevel,
    bevelSize: bevel,
    bevelSegments: 5,
    curveSegments: 24,
  });
  geometry.translate(0, 0, -depth / 2);
  return new THREE.Mesh(geometry, material);
}

function box(w, h, d, material, x, y, z) {
  const mesh = new THREE.Mesh(new THREE.BoxGeometry(w, h, d), material);
  mesh.position.set(x, y, z);
  return mesh;
}

// Wheel arch cut into the bottom edge, drawn while walking the outline from front to rear.
function cutArch(shape, axleX) {
  const cy = MODEL_WHEEL_RADIUS;
  const dx = Math.sqrt(ARCH_RADIUS ** 2 - (cy - SILL_Y) ** 2);
  const a0 = Math.atan2(SILL_Y - cy, dx);
  shape.lineTo(axleX + dx, SILL_Y);
  shape.absarc(axleX, cy, ARCH_RADIUS, a0, Math.PI - a0, false);
}

function bodyShape(withArches) {
  const s = new THREE.Shape();
  s.moveTo(-2.35, 0.26);
  s.lineTo(-2.38, 0.58);
  s.lineTo(-2.25, 0.82);
  s.lineTo(-1.2, 0.9);
  s.lineTo(0.9, 0.9);
  s.lineTo(1.9, 0.7);
  s.lineTo(2.2, 0.55);
  s.lineTo(2.26, 0.38);
  s.lineTo(2.1, SILL_Y);
  if (withArches) {
    cutArch(s, MODEL_FRONT_AXLE_X);
    cutArch(s, MODEL_REAR_AXLE_X);
  }
  s.lineTo(-2.1, SILL_Y);
  s.closePath();
  return s;
}

function createWheel() {
  const R = MODEL_WHEEL_RADIUS;
  const pivot = new THREE.Group(); // steering
  const spin = new THREE.Group(); // rolling
  pivot.add(spin);

  const tread = new THREE.Mesh(new THREE.CylinderGeometry(R, R, TIRE_WIDTH, 32, 1, true), rubber);
  tread.rotation.x = Math.PI / 2;
  spin.add(tread);

  for (const side of [-1, 1]) {
    const wall = new THREE.Mesh(new THREE.RingGeometry(RIM_RADIUS, R, 32), rubber);
    wall.position.z = (side * TIRE_WIDTH) / 2;
    spin.add(wall);
  }

  const barrel = new THREE.Mesh(
    new THREE.CylinderGeometry(RIM_RADIUS, RIM_RADIUS, TIRE_WIDTH, 24, 1, true),
    alloy
  );
  barrel.rotation.x = Math.PI / 2;
  spin.add(barrel);

  const disc = new THREE.Mesh(new THREE.CylinderGeometry(0.17, 0.17, 0.03, 24), brakeDisc);
  disc.rotation.x = Math.PI / 2;
  spin.add(disc);

  for (let k = 0; k < 3; k++) {
    const spoke = box(RIM_RADIUS * 2 - 0.02, 0.04, 0.12, alloy, 0, 0, 0);
    spoke.rotation.z = (k * Math.PI) / 3;
    spin.add(spoke);
  }

  const hub = new THREE.Mesh(new THREE.CylinderGeometry(0.05, 0.05, 0.14, 16), alloy);
  hub.rotation.x = Math.PI / 2;
  spin.add(hub);

  return { pivot, spin };
}

export function createCarModel(
  skin = { color: 0xc1121f, metalness: 0.35, roughness: 0.3, clearcoat: 1 }
) {
  // Paint and tail lights belong to this car, so every car can have its own colour and brake lights.
  // The clearcoat layer gives the glossy, smooth lacquer look.
  const paint = new THREE.MeshPhysicalMaterial({
    color: skin.color,
    metalness: skin.metalness,
    roughness: skin.roughness,
    clearcoat: skin.clearcoat ?? 1,
    clearcoatRoughness: 0.06,
  });
  const taillightMat = new THREE.MeshStandardMaterial({
    color: 0x330000,
    emissive: 0xff1a1a,
    emissiveIntensity: 0.6,
  });

  const root = new THREE.Group(); // world position and heading
  const bodyPivot = new THREE.Group(); // pitch and roll
  const bodyContent = new THREE.Group();
  bodyPivot.position.y = BODY_PIVOT_Y;
  bodyContent.position.y = -BODY_PIVOT_Y;
  root.add(bodyPivot);
  bodyPivot.add(bodyContent);

  // Body: solid centre section plus two side panels that have the wheel arches cut out.
  bodyContent.add(extrude(bodyShape(false), CENTER_HALF_WIDTH * 2, paint));
  const slabDepth = BODY_HALF_WIDTH - CENTER_HALF_WIDTH;
  const slabZ = CENTER_HALF_WIDTH + slabDepth / 2;
  for (const side of [-1, 1]) {
    const slab = extrude(bodyShape(true), slabDepth, paint);
    slab.position.z = side * slabZ;
    bodyContent.add(slab);
  }

  // Cabin: tinted glass block plus a body-coloured roof panel.
  bodyContent.add(
    extrude(
      polygon([
        [-1.25, 0.86],
        [-0.85, 1.24],
        [-0.1, 1.32],
        [0.45, 1.29],
        [1.05, 0.86],
      ]),
      1.46,
      glass,
      0.02
    )
  );
  bodyContent.add(
    extrude(
      polygon([
        [-0.85, 1.25],
        [-0.1, 1.33],
        [0.45, 1.3],
        [0.45, 1.265],
        [-0.1, 1.295],
        [-0.85, 1.215],
      ]),
      1.46,
      paint,
      0.01
    )
  );

  // Aero and details.
  bodyContent.add(box(0.4, 0.03, 1.8, dark, 2.15, 0.2, 0)); // front splitter
  bodyContent.add(box(0.38, 0.03, 1.7, paint, -2.25, 1.1, 0)); // rear wing
  for (const side of [-1, 1]) {
    bodyContent.add(box(0.06, 0.22, 0.04, dark, -2.2, 0.97, side * 0.6)); // wing uprights
    bodyContent.add(box(0.12, 0.07, 0.34, headlightMat, 2.17, 0.58, side * 0.62));
    bodyContent.add(box(0.06, 0.07, 0.4, taillightMat, -2.36, 0.62, side * 0.62));
    bodyContent.add(box(0.12, 0.08, 0.2, paint, 0.55, 1.0, side * 0.92)); // mirrors
  }

  // Interior: floor, dashboard and steering wheel.
  bodyContent.add(box(1.75, 0.02, 1.4, dark, -0.325, 0.91, 0));
  bodyContent.add(box(0.45, 0.12, 1.5, dark, 0.78, 0.96, 0));

  const steeringPivot = new THREE.Group();
  steeringPivot.position.set(0.4, 0.97, EYE.z);
  steeringPivot.rotation.z = -0.35; // column tilt
  const steeringAlign = new THREE.Group();
  steeringAlign.rotation.y = Math.PI / 2; // wheel axis points along the car
  const steeringTurn = new THREE.Group();
  steeringTurn.add(new THREE.Mesh(new THREE.TorusGeometry(0.14, 0.018, 12, 32), dark));
  steeringTurn.add(box(0.26, 0.03, 0.02, dark, 0, 0, 0));
  steeringTurn.add(box(0.03, 0.13, 0.02, dark, 0, -0.065, 0));
  steeringTurn.add(box(0.02, 0.03, 0.025, marker, 0, 0.14, 0)); // top-centre marker
  steeringAlign.add(steeringTurn);
  steeringPivot.add(steeringAlign);
  bodyContent.add(steeringPivot);

  // Driver's eye: a camera placed here looks along the car's forward axis (+X).
  const eye = new THREE.Object3D();
  eye.position.set(EYE.x, EYE.y, EYE.z);
  eye.rotation.y = -Math.PI / 2;
  bodyContent.add(eye);

  // Wheels stay on the ground while the body pitches and rolls.
  const wheelZ = [-1, 1, -1, 1].map((side) => (side * TRACK) / 2);
  const pivots = [];
  const spins = [];
  for (let i = 0; i < 4; i++) {
    const wheel = createWheel();
    root.add(wheel.pivot);
    pivots.push(wheel.pivot);
    spins.push(wheel.spin);
  }

  // Fits the wheels and body to the current car (wheel size, weight distribution).
  function applyDimensions(spec) {
    const scale = spec.wheelRadius / MODEL_WHEEL_RADIUS;
    const wheelX = [spec.cgToFront, spec.cgToFront, -spec.cgToRear, -spec.cgToRear];
    bodyContent.position.x = spec.cgToFront - MODEL_FRONT_AXLE_X;
    bodyPivot.position.y = BODY_PIVOT_Y + (spec.wheelRadius - MODEL_WHEEL_RADIUS);
    for (let i = 0; i < 4; i++) {
      pivots[i].position.set(wheelX[i], spec.wheelRadius, wheelZ[i]);
      spins[i].scale.set(scale, scale, 1);
    }
  }
  applyDimensions(readCarSpec());

  // state: { x, y, z, yaw, steer, spin[4], groundPitch, groundRoll, pitch, roll, brake }
  // groundPitch/groundRoll come from the slope under the car; pitch/roll are the body's lean.
  function update(state) {
    root.position.set(state.x, state.y, state.z);
    // Heading first, then the ground slope (pitch about Z, roll about X).
    root.rotation.set(state.groundRoll, -state.yaw, state.groundPitch, 'YZX');
    bodyPivot.rotation.z = state.pitch; // nose up when accelerating
    bodyPivot.rotation.x = state.roll; // leans outwards in corners
    for (let i = 0; i < 4; i++) spins[i].rotation.z = -state.spin[i];
    pivots[0].rotation.y = -state.steer;
    pivots[1].rotation.y = -state.steer;
    steeringTurn.rotation.z = state.steer * STEERING_WHEEL_RATIO;
    taillightMat.emissiveIntensity = 0.6 + 1.6 * state.brake;
  }

  function placeCamera(camera) {
    eye.updateWorldMatrix(true, false);
    eye.getWorldPosition(camera.position);
    eye.getWorldQuaternion(camera.quaternion);
  }

  function setSkin(next) {
    paint.color.set(next.color);
    paint.metalness = next.metalness;
    paint.roughness = next.roughness;
    paint.clearcoat = next.clearcoat ?? 1;
  }

  // Frees this car's meshes and its own materials when it is removed from the scene.
  function dispose() {
    root.traverse((o) => {
      if (o.geometry) o.geometry.dispose();
    });
    paint.dispose();
    taillightMat.dispose();
  }

  return { root, update, placeCamera, applyDimensions, setSkin, dispose };
}

// Saved parameter presets. Pure logic apart from the storage object passed in
// (localStorage in the browser, a fake in tests).

import { PARAMS, getParam, setParam, resetAll } from './registry.js';

export const PRESETS_KEY = 'vectorchase.presets';
const MAX_NAME_LENGTH = 40;

export function snapshotValues() {
  const values = {};
  for (const p of PARAMS) values[p.id] = getParam(p.id);
  return values;
}

// Resets everything first, so parameters missing from an older preset go back to defaults.
export function applyValues(values) {
  resetAll();
  if (!values || typeof values !== 'object') return;
  for (const p of PARAMS) {
    if (Object.prototype.hasOwnProperty.call(values, p.id)) setParam(p.id, values[p.id]);
  }
}

export function cleanName(name) {
  return String(name ?? '').trim().slice(0, MAX_NAME_LENGTH);
}

// Stored as a list of { name, values }. Anything unreadable counts as "no presets".
function readAll(storage) {
  try {
    const raw = storage.getItem(PRESETS_KEY);
    if (!raw) return [];
    const parsed = JSON.parse(raw);
    if (!Array.isArray(parsed)) return [];
    return parsed.filter(
      (e) => e && typeof e.name === 'string' && e.values && typeof e.values === 'object'
    );
  } catch {
    return [];
  }
}

function writeAll(storage, presets) {
  try {
    storage.setItem(PRESETS_KEY, JSON.stringify(presets));
    return true;
  } catch {
    return false;
  }
}

export function listPresets(storage) {
  return readAll(storage)
    .map((e) => e.name)
    .sort((a, b) => a.localeCompare(b));
}

export function readPreset(storage, name) {
  const found = readAll(storage).find((e) => e.name === name);
  return found ? found.values : null;
}

// Returns true if the preset was stored.
export function savePreset(storage, name, values) {
  const clean = cleanName(name);
  if (!clean) return false;
  const presets = readAll(storage).filter((e) => e.name !== clean);
  presets.push({ name: clean, values });
  return writeAll(storage, presets);
}

// Returns true if a preset was removed.
export function deletePreset(storage, name) {
  const presets = readAll(storage);
  const kept = presets.filter((e) => e.name !== name);
  if (kept.length === presets.length) return false;
  return writeAll(storage, kept);
}

const listeners = new Set();

function getDef(id) {
  const def = defs.get(id);
  if (!def) throw new Error(`Unknown parameter: ${id}`);
  return def;
}

// listener(ids) is called with the ids that actually changed. Returns an unsubscribe function.
export function subscribe(listener) {
  listeners.add(listener);
  return () => listeners.delete(listener);
}

function notify(ids) {
  if (ids.length === 0) return;
  for (const listener of listeners) {
    try {
      listener(ids);
    } catch (err) {
      console.error('Parameter listener failed:', err);
    }
  }
}

export function getParam(id) {
  getDef(id);
  return values.get(id);
}

// Returns the stored value after the write. Invalid input leaves the
// current value unchanged. Out-of-range input is clamped.
export function setParam(id, value) {
  const def = getDef(id);
  const current = values.get(id);
  if (typeof value !== 'number' && typeof value !== 'string') return current;
  if (typeof value === 'string' && value.trim() === '') return current;
  const n = Number(value);
  if (!Number.isFinite(n)) return current;
  const clamped = Math.min(def.max, Math.max(def.min, n));
  if (clamped !== current) {
    values.set(id, clamped);
    notify([id]);
  }
  return clamped;
}

export function resetParam(id) {
  const def = getDef(id);
  if (values.get(id) !== def.default) {
    values.set(id, def.default);
    notify([id]);
  }
  return def.default;
}

export function resetAll() {
  const changed = [];
  for (const def of PARAMS) {
    if (values.get(def.id) !== def.default) {
      values.set(def.id, def.default);
      changed.push(def.id);
    }
  }
  notify(changed);
}

// Tracks held keys and per-frame presses.
// Read presses in beforeFrame(), not in fixedUpdate(), because
// fixedUpdate can run zero times in a frame and would miss them.

const PREVENT_DEFAULT = new Set(['Space', 'ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight']);

// Keys typed into text fields belong to the field, not the game.
function isTextEntry(el) {
  return el instanceof Element && el.matches('input[type="text"], input[type="number"], textarea, select');
}

// Arrow keys and Space must keep working inside sliders and buttons.
function isFormControl(el) {
  return el instanceof Element && el.matches('input, textarea, select, button, summary');
}

export class Input {
  constructor(target = window) {
    this.down = new Set();
    this.pressed = new Set();

    target.addEventListener('keydown', (e) => {
      if (isTextEntry(e.target)) return;
      if (PREVENT_DEFAULT.has(e.code) && !isFormControl(e.target)) e.preventDefault();
      if (!e.repeat) this.pressed.add(e.code);
      this.down.add(e.code);
    });

    target.addEventListener('keyup', (e) => {
      this.down.delete(e.code);
    });

    // Losing focus leaves keys stuck without this.
    target.addEventListener('blur', () => {
      this.down.clear();
      this.pressed.clear();
    });
  }

  isDown(code) {
    return this.down.has(code);
  }

  wasPressed(code) {
    return this.pressed.has(code);
  }

  // Call once per frame, after input has been read.
  endFrame() {
    this.pressed.clear();
  }
}

// Frame driver: beforeFrame -> fixed updates -> render.

export function runLoop({ stepper, beforeFrame, fixedUpdate, render }) {
  let last = performance.now();

  function frame(now) {
    const frameDt = (now - last) / 1000;
    last = now;

    beforeFrame?.(frameDt);
    const { steps, alpha } = stepper.update(frameDt);

    for (let i = 0; i < steps; i++) {
      fixedUpdate(stepper.step);
    }

    render(alpha, { steps, timeScale: stepper.timeScale });
    requestAnimationFrame(frame);
  }

  requestAnimationFrame(frame);
}

// Fixed-timestep accumulator with a time scale.
// Pure logic, no DOM or Three.js imports.

export class FixedStepper {
  constructor(step = 1 / 120, maxSubsteps = 8) {
    this.step = step;
    this.maxSubsteps = maxSubsteps;
    this.accumulator = 0;
    this.timeScale = 1;
  }

  // frameDt is in seconds. Large gaps (tab switches) are clamped so the
  // simulation does not try to catch up on minutes of time.
  update(frameDt) {
    const clampedDt = Math.min(Math.max(frameDt, 0), 0.25);
    this.accumulator += clampedDt * Math.max(this.timeScale, 0);

    let steps = 0;
    while (this.accumulator >= this.step && steps < this.maxSubsteps) {
      this.accumulator -= this.step;
      steps++;
    }
    if (steps === this.maxSubsteps) {
      // Hit the cap: drop the backlog instead of spiraling.
      this.accumulator = 0;
    }

    return { steps, alpha: this.accumulator / this.step };
  }
}

// Fixed-size pool of short-lived particles. Pure logic: no DOM or Three.js imports.

export class ParticlePool {
  constructor(capacity) {
    this.capacity = capacity;
    this.next = 0;
    this.position = new Float32Array(capacity * 3);
    this.velocity = new Float32Array(capacity * 3);
    this.color = new Float32Array(capacity * 3);
    this.size = new Float32Array(capacity);
    this.alpha = new Float32Array(capacity);
    this.age = new Float32Array(capacity);
    this.life = new Float32Array(capacity); // 0 = unused
    this.lift = new Float32Array(capacity);
    this.startSize = new Float32Array(capacity);
    this.endSize = new Float32Array(capacity);
    this.startAlpha = new Float32Array(capacity);
  }

  // lift: m/s^2 added to the vertical speed (negative falls, positive rises).
  // When the pool is full the oldest particle is overwritten.
  emit({ x, y, z, vx = 0, vy = 0, vz = 0, life, startSize, endSize, alpha, color = [1, 1, 1], lift = 0 }) {
    const i = this.next;
    this.next = (this.next + 1) % this.capacity;
    const k = i * 3;
    this.position[k] = x;
    this.position[k + 1] = y;
    this.position[k + 2] = z;
    this.velocity[k] = vx;
    this.velocity[k + 1] = vy;
    this.velocity[k + 2] = vz;
    this.color[k] = color[0];
    this.color[k + 1] = color[1];
    this.color[k + 2] = color[2];
    this.age[i] = 0;
    this.life[i] = life;
    this.lift[i] = lift;
    this.startSize[i] = startSize;
    this.endSize[i] = endSize;
    this.startAlpha[i] = alpha;
    this.size[i] = startSize;
    this.alpha[i] = alpha;
  }

  update(dt) {
    for (let i = 0; i < this.capacity; i++) {
      if (this.life[i] <= 0) continue;
      this.age[i] += dt;
      if (this.age[i] >= this.life[i]) {
        this.life[i] = 0;
        this.size[i] = 0;
        this.alpha[i] = 0;
        continue;
      }
      const t = this.age[i] / this.life[i];
      const k = i * 3;
      this.velocity[k + 1] += this.lift[i] * dt;
      this.position[k] += this.velocity[k] * dt;
      this.position[k + 1] += this.velocity[k + 1] * dt;
      this.position[k + 2] += this.velocity[k + 2] * dt;
      this.size[i] = this.startSize[i] + (this.endSize[i] - this.startSize[i]) * t;
      this.alpha[i] = this.startAlpha[i] * (1 - t);
    }
  }

  clear() {
    this.life.fill(0);
    this.size.fill(0);
    this.alpha.fill(0);
  }

  get activeCount() {
    let n = 0;
    for (let i = 0; i < this.capacity; i++) if (this.life[i] > 0) n++;
    return n;
  }
}

// Ring buffer of road-mark quads. Pure logic: no DOM or Three.js imports.
// Each quad is 4 vertices (12 numbers in `positions`): prev+n, prev-n, cur+n, cur-n.

const MIN_SEGMENT = 0.25; // m: shorter moves are ignored
const MAX_SEGMENT = 5; // m: longer jumps (a respawn, say) start a new line

export class SkidBuffer {
  constructor(capacity, width = 0.22) {
    this.capacity = capacity;
    this.width = width;
    this.positions = new Float32Array(capacity * 12);
    this.count = 0; // quads stored, capped at capacity
    this.next = 0; // where the next quad goes
    this.last = new Map(); // wheel key -> last marked point
  }

  // Adds a mark from the wheel's previous marked point to (x, y, z).
  add(key, x, y, z) {
    const prev = this.last.get(key);
    if (!prev) {
      this.last.set(key, { x, y, z });
      return;
    }
    const dx = x - prev.x;
    const dz = z - prev.z;
    const len = Math.hypot(dx, dz);
    if (len < MIN_SEGMENT) return;
    if (len > MAX_SEGMENT) {
      this.last.set(key, { x, y, z });
      return;
    }

    const nx = ((-dz / len) * this.width) / 2;
    const nz = ((dx / len) * this.width) / 2;
    const p = this.positions;
    const base = this.next * 12;
    p.set([prev.x + nx, prev.y, prev.z + nz], base);
    p.set([prev.x - nx, prev.y, prev.z - nz], base + 3);
    p.set([x + nx, y, z + nz], base + 6);
    p.set([x - nx, y, z - nz], base + 9);
    this.next = (this.next + 1) % this.capacity;
    this.count = Math.min(this.count + 1, this.capacity);

    prev.x = x;
    prev.y = y;
    prev.z = z;
  }

  // Call when a wheel stops sliding, so its next mark starts a new line.
  end(key) {
    this.last.delete(key);
  }

  clear() {
    this.count = 0;
    this.next = 0;
    this.last.clear();
  }
}

// Drift scoring, combo and boost meter. Pure logic: no DOM or Three.js imports.

const MIN_SPEED = 10; // m/s
const MIN_ANGLE = 0.17; // rad (about 10 degrees) of sideways slide to count as a drift
const MAX_ANGLE = 1.3;
const BANK_AFTER = 1; // s of drifting needed before points are kept
const IDLE_TO_BANK = 0.4; // s without drifting that ends a drift
const FILL_RATE = 0.12; // boost meter per second of drifting (about 8 s fills it)
const BOOST_SECONDS = 3; // a full meter lasts this long

export class StyleTracker {
  constructor() {
    this.reset();
  }

  reset() {
    this.meter = 0; // boost, 0..1
    this.boosting = false;
    this.driftPoints = 0;
    this.combo = 0; // seconds of the current drift
    this.multiplier = 1;
    this.idle = 0;
    this.total = 0;
    this.best = 0;
    this.popup = 0; // seconds left to show the last banked drift
    this.popupText = '';
  }

  // car: { u, v, wheelSlip }. crashed: the car hit something hard this step.
  update(dt, car, { boostHeld = false, crashed = false } = {}) {
    this.popup = Math.max(0, this.popup - dt);
    const speed = Math.hypot(car.u, car.v);
    const angle = Math.abs(Math.atan2(car.v, Math.max(car.u, 0.001)));
    const sliding = Math.max(...car.wheelSlip) > 1.0;

    if (crashed) {
      this.driftPoints = 0;
      this.combo = 0;
      this.multiplier = 1;
    } else if (car.u > 0 && speed > MIN_SPEED && sliding && angle > MIN_ANGLE && angle < MAX_ANGLE) {
      this.idle = 0;
      this.combo += dt;
      this.multiplier = Math.min(5, 1 + Math.floor(this.combo));
      this.driftPoints += dt * speed * angle * 8 * this.multiplier;
      this.meter = Math.min(1, this.meter + dt * FILL_RATE);
    } else if (this.driftPoints > 0) {
      this.idle += dt;
      if (this.idle > IDLE_TO_BANK) {
        if (this.combo >= BANK_AFTER) {
          const banked = Math.round(this.driftPoints);
          this.total += banked;
          this.best = Math.max(this.best, banked);
          this.popup = 2;
          this.popupText = `+${banked}`;
        }
        this.driftPoints = 0;
        this.combo = 0;
        this.multiplier = 1;
        this.idle = 0;
      }
    }

    this.boosting = boostHeld && this.meter > 0;
    if (this.boosting) this.meter = Math.max(0, this.meter - dt / BOOST_SECONDS);
  }
}

// Car-to-car and car-to-wall collisions. Pure logic: no DOM or Three.js imports.
// Each car is three overlapping circles along its length. Overlaps are pushed apart, and the
// bodies exchange momentum with an impulse that includes spin, so glancing hits turn the cars.

import { YAW_GYRATION } from './vehicle.js';

const CIRCLE_RADIUS = 0.95;
const CIRCLE_OFFSETS = [1.35, 0, -1.35]; // m forward of the centre of gravity
const RESTITUTION = 0.2;
const BOUNCE_THRESHOLD = 0.5; // m/s: slower impacts do not bounce
const CAR_FRICTION = 0.15;
const WALL_FRICTION = 0.1;
const WALL_SPIN_DAMP = 0.6; // share of the yaw rate kept after each wall contact
const SLOP = 0.005; // m of extra separation so cars do not stay in contact

// A car as a rigid body: world velocity of the centre of gravity and yaw rate.
function bodyOf(car, mass) {
  const c = Math.cos(car.yaw);
  const s = Math.sin(car.yaw);
  return {
    car,
    mass,
    inertia: mass * YAW_GYRATION * YAW_GYRATION,
    vx: car.u * c - car.v * s,
    vz: car.u * s + car.v * c,
    r: car.r,
  };
}

// Writes the body's velocity back into the car's own forward/sideways speeds.
function store(body) {
  const c = Math.cos(body.car.yaw);
  const s = Math.sin(body.car.yaw);
  body.car.u = body.vx * c + body.vz * s;
  body.car.v = -body.vx * s + body.vz * c;
  body.car.r = body.r;
}

// Adds an impulse (jx, jz) applied at lever arm (rx, rz) from the body's centre.
function push(body, jx, jz, rx, rz) {
  body.vx += jx / body.mass;
  body.vz += jz / body.mass;
  body.r += (rx * jz - rz * jx) / body.inertia;
}

function circleAt(car, offset) {
  return { x: car.x + Math.cos(car.yaw) * offset, z: car.z + Math.sin(car.yaw) * offset };
}

// Exchanges momentum at one contact. (nx, nz) points from a into b; b = null is a fixed wall.
function impulse(a, b, px, pz, nx, nz, friction) {
  const rax = px - a.car.x;
  const raz = pz - a.car.z;
  const rbx = b ? px - b.car.x : 0;
  const rbz = b ? pz - b.car.z : 0;

  // Relative velocity of the contact point on b compared with a.
  const rvx = (b ? b.vx - b.r * rbz : 0) - (a.vx - a.r * raz);
  const rvz = (b ? b.vz + b.r * rbx : 0) - (a.vz + a.r * rax);
  const vn = rvx * nx + rvz * nz;
  if (vn >= 0) return; // already moving apart

  // Inverse mass seen along a direction, including how much the contact makes the bodies spin.
  const inverseMass = (dx, dz) => {
    const ca = rax * dz - raz * dx;
    let inv = 1 / a.mass + (ca * ca) / a.inertia;
    if (b) {
      const cb = rbx * dz - rbz * dx;
      inv += 1 / b.mass + (cb * cb) / b.inertia;
    }
    return inv;
  };

  const e = -vn > BOUNCE_THRESHOLD ? RESTITUTION : 0;
  const j = (-(1 + e) * vn) / inverseMass(nx, nz);
  push(a, -j * nx, -j * nz, rax, raz);
  if (b) push(b, j * nx, j * nz, rbx, rbz);

  // Friction along the contact, limited by the normal impulse.
  const tx = -nz;
  const tz = nx;
  const vt = rvx * tx + rvz * tz;
  const jt = Math.max(-friction * j, Math.min(friction * j, -vt / inverseMass(tx, tz)));
  push(a, -jt * tx, -jt * tz, rax, raz);
  if (b) push(b, jt * tx, jt * tz, rbx, rbz);
}

export function collideCars(carA, carB, spec) {
  const dx = carB.x - carA.x;
  const dz = carB.z - carA.z;
  if (dx * dx + dz * dz > 36) return; // centres more than 6 m apart: cannot touch

  const a = bodyOf(carA, spec.mass);
  const b = bodyOf(carB, spec.mass);
  for (const offsetA of CIRCLE_OFFSETS) {
    for (const offsetB of CIRCLE_OFFSETS) {
      // Measured fresh each time, because earlier pushes move the cars.
      const pa = circleAt(carA, offsetA);
      const pb = circleAt(carB, offsetB);
      const ddx = pb.x - pa.x;
      const ddz = pb.z - pa.z;
      const dist = Math.hypot(ddx, ddz);
      const overlap = 2 * CIRCLE_RADIUS - dist;
      if (overlap <= 0) continue;

      const nx = dist > 1e-6 ? ddx / dist : 1;
      const nz = dist > 1e-6 ? ddz / dist : 0;
      impulse(a, b, (pa.x + pb.x) / 2, (pa.z + pb.z) / 2, nx, nz, CAR_FRICTION);
      const shift = (overlap + SLOP) / 2;
      carA.x -= nx * shift;
      carA.z -= nz * shift;
      carB.x += nx * shift;
      carB.z += nz * shift;
    }
  }
  store(a);
  store(b);
}

// world needs lateral(x, z) and wallOffset (see createWorld).
export function collideWall(car, world, spec) {
  const body = bodyOf(car, spec.mass);
  const limit = world.wallOffset - CIRCLE_RADIUS; // how far a circle centre may be from the centre line
  for (const offset of CIRCLE_OFFSETS) {
    const c = circleAt(car, offset); // measured fresh each time, because earlier pushes move the car
    const lat = world.lateral(c.x, c.z);
    if (!lat) continue;
    const depth = Math.abs(lat.offset) - limit;
    if (depth <= 0) continue;

    const side = lat.offset > 0 ? 1 : -1;
    const nx = lat.nx * side; // points from the car into the wall
    const nz = lat.nz * side;
    const toWall = world.wallOffset - Math.abs(lat.offset);
    impulse(body, null, c.x + nx * toWall, c.z + nz * toWall, nx, nz, WALL_FRICTION);
    body.r *= WALL_SPIN_DAMP;
    car.x -= nx * (depth + SLOP);
    car.z -= nz * (depth + SLOP);
  }
  store(body);
}

export function resolveCollisions(cars, world, spec) {
  for (const car of cars) collideWall(car, world, spec);
  for (let i = 0; i < cars.length; i++) {
    for (let j = i + 1; j < cars.length; j++) collideCars(cars[i], cars[j], spec);
  }
  // A car shoved by another car may now be inside a wall.
  for (const car of cars) collideWall(car, world, spec);
}

// Turns registry values (UI units) into the SI values the physics uses, plus derived values.
// Called once per physics step, so a changed parameter takes effect on the next step.
// Pure logic: no DOM or Three.js imports.

import { getParam } from '../config/registry.js';

export const WHEELBASE = 2.7; // m, fixed by the body model
export const TRACK = 1.6; // m, fixed by the body model

const DEG = Math.PI / 180;
const WHEEL_INERTIA_FACTOR = 0.7; // I = factor * mass * radius^2

export function readCarSpec() {
  const frontWeight = getParam('chassis.frontWeight') / 100;
  const wheelRadius = getParam('wheel.radius');
  const wheelMass = getParam('wheel.mass');
  const redline = getParam('engine.redline');
  const shiftRpm = Math.min(getParam('drivetrain.shiftRpm'), redline - 200);
  const brakeTotal = getParam('brakes.torque');
  const brakeBias = getParam('brakes.bias') / 100;

  return {
    mass: getParam('chassis.mass'),
    wheelbase: WHEELBASE,
    track: TRACK,
    // More weight on the front axle means the centre of gravity sits closer to it.
    cgToFront: (1 - frontWeight) * WHEELBASE,
    cgToRear: frontWeight * WHEELBASE,
    cgHeight: getParam('chassis.cgHeight'),
    rollShareFront: getParam('suspension.rollFront') / 100,

    dragArea: getParam('aero.dragArea'),
    downforceArea: getParam('aero.downforce'),

    enginePower: getParam('engine.power') * 1000, // W
    redline,
    engineBraking: getParam('engine.braking') / 100,

    finalDrive: getParam('drivetrain.finalDrive'),
    shiftRpm,
    downshiftMaxRpm: shiftRpm - 600,
    frontBias: getParam('drivetrain.frontBias') / 100,

    wheelRadius,
    wheelInertia: WHEEL_INERTIA_FACTOR * wheelMass * wheelRadius * wheelRadius,

    friction: getParam('tire.friction'),
    peakSlipTan: Math.tan(getParam('tire.peakSlipAngle') * DEG),
    peakSlipRatio: getParam('tire.peakSlipRatio'),
    loadSensitivity: getParam('tire.loadSensitivity') / 100,
    rollingResistance: getParam('tire.rollingResistance'),

    // Total brake torque is split front/rear, then shared between the two wheels of an axle.
    frontBrakeTorque: (brakeTotal * brakeBias) / 2,
    rearBrakeTorque: (brakeTotal * (1 - brakeBias)) / 2,

    assistStability: getParam('assist.stability') / 100,
    assistCountersteer: getParam('assist.countersteer') / 100,
    boostPower: getParam('assist.boost') / 100,

    maxSteer: getParam('steering.maxAngle') * DEG,
    steerSpeedRef: getParam('steering.speedRef'),
  };
}

// Planar four-wheel vehicle model. Pure logic: no DOM or Three.js imports.
//
// World: forward = (cos yaw, sin yaw) in the XZ plane, right = (-sin yaw, cos yaw).
// Body axes: u = forward speed, v = speed to the right, r = yaw rate (positive = turning right).
// Wheel order: 0 front-left, 1 front-right, 2 rear-left, 3 rear-right.
// Tunable values come from the registry through readCarSpec(), once per fixed step.

import { readCarSpec } from './spec.js';

const G = 9.81;
const AIR_DENSITY = 1.2;
const SUBSTEPS = 6;
const RPM_TO_RADS = (Math.PI * 2) / 60;
const RADS_TO_RPM = 60 / (Math.PI * 2);
export const YAW_GYRATION = 1.25; // m, yaw inertia = mass * gyration^2
const DOWNFORCE_FRONT_SHARE = 0.4;
const FLAT_GROUND = { groundHeight: () => 0 };

// Engine and gearbox
const IDLE_RPM = 1000;
const LAUNCH_RPM = 3500; // clutch slip rpm used for torque when starting from rest
const TORQUE_CURVE_REDLINE = 7500; // the unit torque curve below ends here; it is stretched to the real redline
const TORQUE_CURVE = [
  [1000, 0.7],
  [2000, 0.82],
  [3000, 0.92],
  [4000, 1.0],
  [5000, 1.0],
  [6000, 0.95],
  [7000, 0.82],
  [7500, 0.7],
];
const GEAR_RATIOS = [3.6, 2.3, 1.65, 1.25, 1.0, 0.82];
const REVERSE_RATIO = 3.4;
const DRIVE_EFFICIENCY = 0.92;
const DOWNSHIFT_RPM = 2800;
const SHIFT_TIME = 0.25; // s, torque cut during a shift

// Tires
const CURVE_C = 1.5;
const CURVE_B = Math.tan(Math.PI / (2 * CURVE_C)); // puts the force peak at normalized slip 1
const CURVE_SLOPE = CURVE_B * CURVE_C;
const V_MIN_LONG = 3; // m/s, lowest speed used when computing slip ratio
const V_MIN_LAT = 2; // m/s, lowest speed used when computing slip angle
const TRACTION_LIMIT = 0.92; // drive torque cap as a fraction of peak grip
const BRAKE_LIMIT = 0.97; // brake torque cap as a fraction of peak grip

// Driver input smoothing
const THROTTLE_UP = 3;
const THROTTLE_DOWN = 6;
const BRAKE_UP = 8;
const BRAKE_DOWN = 12;
const STEER_RATE = 3.5;
const STEER_RETURN = 5;
const ACCEL_FILTER = 0.06; // s, suspension-like smoothing of body accelerations

function curveTorque(rpm) {
  if (rpm <= TORQUE_CURVE[0][0]) return TORQUE_CURVE[0][1];
  for (let i = 1; i < TORQUE_CURVE.length; i++) {
    const [r1, t1] = TORQUE_CURVE[i];
    if (rpm <= r1) {
      const [r0, t0] = TORQUE_CURVE[i - 1];
      return t0 + ((t1 - t0) * (rpm - r0)) / (r1 - r0);
    }
  }
  return 0; // past the end of the curve
}

// Peak power of the unscaled curve, so the registry's engine power sets the real peak.
const UNIT_PEAK_POWER = (() => {
  let best = 0;
  for (let rpm = IDLE_RPM; rpm <= TORQUE_CURVE_REDLINE; rpm += 10) {
    best = Math.max(best, curveTorque(rpm) * rpm * RPM_TO_RADS);
  }
  return best;
})();

function totalRatio(gear, finalDrive) {
  return gear > 0 ? GEAR_RATIOS[gear - 1] * finalDrive : -REVERSE_RATIO * finalDrive;
}

function clamp(x, lo, hi) {
  return Math.min(hi, Math.max(lo, x));
}

function approach(current, target, up, down) {
  return target > current ? Math.min(target, current + up) : Math.max(target, current - down);
}

export class Vehicle {
  constructor({ x = 0, z = 0, yaw = 0, ground = FLAT_GROUND } = {}) {
    this.ground = ground; // anything with groundHeight(x, z); sample(x, z) adds surface grip
    this.x = x;
    this.z = z;
    this.yaw = yaw;
    this.y = 0; // height of the car, from the ground under the wheels
    this.pitch = 0; // slope under the car in rad (positive = nose up)
    this.roll = 0; // cross slope under the car in rad (positive = right side lower)
    this.slope = 0; // sin(pitch), used for gravity along the road
    this.surfaceGrip = [1, 1, 1, 1]; // grip under each wheel: 1 on tarmac, less on grass
    this.surfaceDrag = 1; // rolling resistance multiplier
    this.handbrake = 0; // 0..1, locks up the rear tires' grip to start drifts
    this.boosting = false; // extra engine power while true
    this.wheelSlip = [0, 0, 0, 0]; // how hard each tire works: 1 is peak grip, above 1 is sliding
    this.u = 0;
    this.v = 0;
    this.r = 0;

    this.wheelSpeed = [0, 0, 0, 0]; // rad/s, positive = rolling forward
    this.wheelSpin = [0, 0, 0, 0]; // accumulated angle in rad, for rendering

    this.throttle = 0;
    this.brake = 0;
    this.steerInput = 0;
    this.steer = 0; // front wheel angle in rad, positive = right
    this.gear = 1; // 1..6, or -1 for reverse
    this.shiftTimer = 0;
    this.rpm = IDLE_RPM;

    this.accelX = 0; // filtered body accelerations in m/s^2
    this.accelY = 0;
    this.fz = [0, 0, 0, 0];
    this._mu = [0, 0, 0, 0];
    this._fy = [0, 0, 0, 0];

    this.recoveries = 0; // how many times the numbers blew up and the car was reset

    this._updateGround(readCarSpec());
    this.prev = {
      x,
      y: this.y,
      z,
      yaw,
      pitch: this.pitch,
      roll: this.roll,
      steer: 0,
      spin: [0, 0, 0, 0],
    };
  }

  // controls: { forward, back, left, right } booleans,
  // or { analog: true, throttle, brake, steer } with exact values (used by bots)
  step(dt, controls) {
    this._savePrev();
    const spec = readCarSpec();

    this._updateDriver(dt, controls, spec);
    this._updateGearbox(dt, spec);
    this._updateGround(spec);

    const sub = dt / SUBSTEPS;
    for (let i = 0; i < SUBSTEPS; i++) this._substep(sub, spec);
    for (let i = 0; i < 4; i++) this.wheelSpin[i] += this.wheelSpeed[i] * dt;

    if (!this._isFinite()) this._recover();
  }

  // Puts the car back on the ground at a position, standing still.
  reset(x, z, yaw) {
    this.x = x;
    this.z = z;
    this.yaw = yaw;
    this.u = 0;
    this.v = 0;
    this.r = 0;
    this.wheelSpeed.fill(0);
    this._fy.fill(0);
    this.wheelSlip.fill(0);
    this.throttle = 0;
    this.brake = 0;
    this.steerInput = 0;
    this.steer = 0;
    this.handbrake = 0;
    this.boosting = false;
    this.gear = 1;
    this.shiftTimer = 0;
    this.accelX = 0;
    this.accelY = 0;
    this._updateGround(readCarSpec());
    this._savePrev(); // no smearing between the old and new position when drawing
  }

  _savePrev() {
    const p = this.prev;
    p.x = this.x;
    p.z = this.z;
    p.yaw = this.yaw;
    p.y = this.y;
    p.pitch = this.pitch;
    p.roll = this.roll;
    p.steer = this.steer;
    for (let i = 0; i < 4; i++) p.spin[i] = this.wheelSpin[i];
  }

  // Height, pitch, roll and surface under the four wheels.
  _updateGround(spec) {
    const { cgToFront: a, cgToRear: b, track } = spec;
    const cosYaw = Math.cos(this.yaw);
    const sinYaw = Math.sin(this.yaw);
    const half = track / 2;
    // px is forward of the centre of gravity, py is to the right.
    const at = (px, py) => {
      const x = this.x + cosYaw * px - sinYaw * py;
      const z = this.z + sinYaw * px + cosYaw * py;
      return this.ground.sample
        ? this.ground.sample(x, z)
        : { height: this.ground.groundHeight(x, z), grip: 1, drag: 1 };
    };
    const wheels = [at(a, -half), at(a, half), at(-b, -half), at(-b, half)];
    const [fl, fr, rl, rr] = wheels.map((w) => w.height);

    wheels.forEach((w, i) => {
      this.surfaceGrip[i] = w.grip;
    });
    this.surfaceDrag = (wheels[0].drag + wheels[1].drag + wheels[2].drag + wheels[3].drag) / 4;

    const rise = (fl + fr) / 2 - (rl + rr) / 2;
    this.y = (fl + fr + rl + rr) / 4;
    this.pitch = Math.atan2(rise, a + b);
    this.slope = rise / Math.hypot(a + b, rise);
    this.roll = Math.atan2((fl + rl) / 2 - (fr + rr) / 2, track);
  }

  // Average speed of the driven wheels, weighted by the front/rear drive split.
  _driveSpeed(spec) {
    const w = this.wheelSpeed;
    return (1 - spec.frontBias) * ((w[2] + w[3]) / 2) + spec.frontBias * ((w[0] + w[1]) / 2);
  }

  _updateDriver(dt, c, spec) {
    let throttleTarget = 0;
    let brakeTarget = 0;
    if (c.forward && c.back) {
      brakeTarget = 1;
    } else if (c.forward) {
      if (this.u < -1) {
        brakeTarget = 1; // still rolling backwards: brake first
      } else {
        throttleTarget = 1;
        if (this.gear < 0) this.gear = 1;
      }
    } else if (c.back) {
      if (this.u > 1) {
        brakeTarget = 1; // still rolling forwards: brake first
      } else {
        throttleTarget = 1;
        if (this.gear > 0) this.gear = -1;
      }
    }
    if (c.analog) {
      // Bots give exact pedal and steering values instead of key presses.
      throttleTarget = clamp(c.throttle, 0, 1);
      brakeTarget = clamp(c.brake, 0, 1);
      if (this.gear < 0) this.gear = 1;
    }
    // Driving assists (players only; bots steer themselves). Only while moving forward.
    const slide = this.u > 0 && Math.hypot(this.u, this.v) > 5 ? Math.atan2(this.v, Math.max(this.u, 3)) : 0;
    const spin = c.analog ? 0 : clamp((Math.abs(slide) - 0.35) / 0.5, 0, 1) * spec.assistStability;
    if (spin > 0) {
      throttleTarget *= 1 - spin;
      if (this.u > 3) brakeTarget = Math.max(brakeTarget, 0.5 * spin);
    }
    this.handbrake = approach(this.handbrake, c.handbrake ? 1 : 0, 10 * dt, 6 * dt);
    this.boosting = !!c.boost && this.u > 1;
    this.throttle = approach(this.throttle, throttleTarget, THROTTLE_UP * dt, THROTTLE_DOWN * dt);
    this.brake = approach(this.brake, brakeTarget, BRAKE_UP * dt, BRAKE_DOWN * dt);

    const steerTarget = c.analog ? clamp(c.steer, -1, 1) : (c.right ? 1 : 0) - (c.left ? 1 : 0);
    const rate = steerTarget === 0 ? STEER_RETURN : STEER_RATE;
    this.steerInput = approach(this.steerInput, steerTarget, rate * dt, rate * dt);
    this.steer = this.steerInput * (spec.maxSteer / (1 + (this.u / spec.steerSpeedRef) ** 2));
    if (!c.analog && slide !== 0) {
      // Countersteer into the slide, stepping back while the player is steering.
      const hands = Math.max(1 - Math.abs(this.steerInput), spin);
      this.steer += clamp(spec.assistCountersteer * hands * slide, -0.35, 0.35);
      this.steer = clamp(this.steer, -0.45, 0.45);
    }
  }

  _updateGearbox(dt, spec) {
    if (this.shiftTimer > 0) this.shiftTimer = Math.max(0, this.shiftTimer - dt);
    if (this.gear < 1 || this.shiftTimer > 0) return;

    const rpm =
      Math.abs(this._driveSpeed(spec)) * totalRatio(this.gear, spec.finalDrive) * RADS_TO_RPM;
    if (rpm > spec.shiftRpm && this.gear < GEAR_RATIOS.length) {
      this.gear++;
      this.shiftTimer = SHIFT_TIME;
    } else if (this.gear > 1 && rpm < DOWNSHIFT_RPM) {
      const lowerRpm =
        (rpm * totalRatio(this.gear - 1, spec.finalDrive)) / totalRatio(this.gear, spec.finalDrive);
      if (lowerRpm < spec.downshiftMaxRpm) {
        this.gear--;
        this.shiftTimer = SHIFT_TIME;
      }
    }
  }

  // Largest torque a wheel can pass to the road without exceeding its grip,
  // after subtracting what the tire is already using for cornering.
  _capacity(i, limit, wheelRadius) {
    const grip = this._mu[i] * this.fz[i];
    if (grip < 1) return 0;
    const used = Math.min(1, this._fy[i] / grip);
    return limit * grip * wheelRadius * Math.max(0.2, Math.sqrt(1 - used * used));
  }

  _substep(dt, spec) {
    const {
      cgToFront: a,
      cgToRear: b,
      track,
      cgHeight: h,
      wheelRadius: R,
      wheelInertia: I,
      mass: m,
    } = spec;
    const L = a + b;
    const w = this.wheelSpeed;
    const fz = this.fz;
    const mu = this._mu;
    const u = this.u;
    const v = this.v;
    const r = this.r;

    // Wheel loads: static split, downforce, and longitudinal and lateral load transfer.
    // accelY > 0 means accelerating to the right, which loads the left wheels.
    const dLong = (m * this.accelX * h) / L;
    const dLat = (m * this.accelY * h) / track;
    const dLatF = dLat * spec.rollShareFront;
    const dLatR = dLat - dLatF;
    const downforce = 0.5 * AIR_DENSITY * spec.downforceArea * u * u;
    const downFront = downforce * DOWNFORCE_FRONT_SHARE;
    const wf = (m * G * b) / L + downFront;
    const wr = (m * G * a) / L + (downforce - downFront);
    fz[0] = Math.max(0, wf / 2 - dLong / 2 + dLatF);
    fz[1] = Math.max(0, wf / 2 - dLong / 2 - dLatF);
    fz[2] = Math.max(0, wr / 2 + dLong / 2 + dLatR);
    fz[3] = Math.max(0, wr / 2 + dLong / 2 - dLatR);

    const fzNom = (m * G) / 4;
    for (let i = 0; i < 4; i++) {
      mu[i] =
        spec.friction *
        this.surfaceGrip[i] *
        (i >= 2 ? 1 - 0.6 * this.handbrake : 1) *
        clamp(1 - spec.loadSensitivity * (fz[i] / fzNom - 1), 0.6, 1.2);
    }

    // Drivetrain: engine rpm follows the driven wheels, except while the clutch slips at launch.
    const wd = this._driveSpeed(spec);
    const ratio = totalRatio(this.gear, spec.finalDrive);
    const wheelRpm = Math.abs(wd * ratio) * RADS_TO_RPM;
    const rpm = Math.max(wheelRpm, IDLE_RPM + (LAUNCH_RPM - IDLE_RPM) * this.throttle);
    this.rpm = rpm;

    // The unit torque curve is stretched to the real redline; power scales with the stretch.
    const redlineScale = spec.redline / TORQUE_CURVE_REDLINE;
    const torqueScale = spec.enginePower / (UNIT_PEAK_POWER * redlineScale);
    let engineTorque = 0;
    if (this.shiftTimer <= 0 && rpm <= spec.redline) {
      engineTorque =
        this.throttle * curveTorque(rpm / redlineScale) * torqueScale * (this.boosting ? 1 + spec.boostPower : 1);
    }
    const dragTorque =
      spec.engineBraking *
      torqueScale *
      (1 - this.throttle) *
      clamp((wheelRpm - 1100) / (spec.redline - 1100), 0, 1);
    const axleTorque =
      engineTorque * ratio * DRIVE_EFFICIENCY - Math.sign(wd) * dragTorque * Math.abs(ratio);

    // Open differential on each driven axle: equal torque, limited by the weaker wheel.
    const frontCap = Math.min(
      this._capacity(0, TRACTION_LIMIT, R),
      this._capacity(1, TRACTION_LIMIT, R)
    );
    const rearCap = Math.min(
      this._capacity(2, TRACTION_LIMIT, R),
      this._capacity(3, TRACTION_LIMIT, R)
    );
    const driveFront = clamp((axleTorque * spec.frontBias) / 2, -frontCap, frontCap);
    const driveRear = clamp((axleTorque * (1 - spec.frontBias)) / 2, -rearCap, rearCap);

    const cosSteer = Math.cos(this.steer);
    const sinSteer = Math.sin(this.steer);
    let sumFx = 0;
    let sumFy = 0;
    let moment = 0;

    for (let i = 0; i < 4; i++) {
      const front = i < 2;
      const px = front ? a : -b;
      const py = i % 2 === 0 ? -track / 2 : track / 2;
      const c = front ? cosSteer : 1;
      const s = front ? sinSteer : 0;

      // Contact patch velocity in the wheel's own frame.
      const vx = u - r * py;
      const vy = v + r * px;
      const vl = vx * c + vy * s;
      const vt = -vx * s + vy * c;

      const kappa = (w[i] * R - vl) / Math.max(Math.abs(vl), V_MIN_LONG);
      const tanAlpha = vt / Math.max(Math.abs(vl), V_MIN_LAT);
      const nx = kappa / spec.peakSlipRatio;
      const ny = tanAlpha / spec.peakSlipTan;
      const slip = Math.hypot(nx, ny);
      this.wheelSlip[i] = slip;

      let fxw = 0;
      let fyw = 0;
      if (slip > 1e-9) {
        const mag = mu[i] * fz[i] * Math.sin(CURVE_C * Math.atan(CURVE_B * slip));
        fxw = (mag * nx) / slip;
        fyw = (-mag * ny) / slip;
      }
      this._fy[i] = Math.abs(fyw);

      const fbx = fxw * c - fyw * s;
      const fby = fxw * s + fyw * c;
      sumFx += fbx;
      sumFy += fby;
      moment += px * fby - py * fbx;

      // Wheel spin: drive torque minus the road's reaction, then brakes.
      // The reaction is stiff at low speed, so the update is damped by its linear stiffness.
      const drive = front ? driveFront : driveRear;
      const stiffness =
        (((mu[i] * fz[i] * CURVE_SLOPE) / spec.peakSlipRatio) * R * R) /
        (Math.max(Math.abs(vl), V_MIN_LONG) * I);
      let wn = w[i] + (dt * (drive - fxw * R)) / I / (1 + dt * stiffness);

      const brakeTorque = Math.min(
        this.brake * (front ? spec.frontBrakeTorque : spec.rearBrakeTorque),
        this._capacity(i, BRAKE_LIMIT, R)
      );
      const dw = (dt * brakeTorque) / I;
      wn = Math.abs(wn) <= dw ? 0 : wn - Math.sign(wn) * dw;
      w[i] = wn;
    }

    // Body: tire forces plus air and rolling resistance, and gravity along the slope.
    const aero = -0.5 * AIR_DENSITY * spec.dragArea * u * Math.abs(u);
    const rolling = -spec.rollingResistance * this.surfaceDrag * m * G * Math.tanh(u / 0.5);
    const fxBody = sumFx + aero + rolling;
    const gravity = -m * G * this.slope; // pulls the car back uphill and forward downhill
    const izz = m * YAW_GYRATION * YAW_GYRATION;

    this.u += ((fxBody + gravity) / m + r * v) * dt;
    this.v += (sumFy / m - r * u) * dt;
    this.r += (moment / izz) * dt;

    const cosYaw = Math.cos(this.yaw);
    const sinYaw = Math.sin(this.yaw);
    this.x += (this.u * cosYaw - this.v * sinYaw) * dt;
    this.z += (this.u * sinYaw + this.v * cosYaw) * dt;
    this.yaw += this.r * dt;

    const k = 1 - Math.exp(-dt / ACCEL_FILTER);
    this.accelX += (fxBody / m - this.accelX) * k;
    this.accelY += (sumFy / m - this.accelY) * k;
  }

  _isFinite() {
    const values = [this.x, this.z, this.yaw, this.u, this.v, this.r, ...this.wheelSpeed];
    return values.every(Number.isFinite);
  }

  // Safety net: if the numbers ever blow up, stop the car where it was.
  _recover() {
    this.recoveries++;
    this.x = this.prev.x;
    this.z = this.prev.z;
    this.yaw = this.prev.yaw;
    this.u = 0;
    this.v = 0;
    this.r = 0;
    this.wheelSpeed.fill(0);
    this._fy.fill(0);
    this.wheelSlip.fill(0);
    this.accelX = 0;
    this.accelY = 0;
    this.throttle = 0;
    this.brake = 0;
    this.shiftTimer = 0;
  }
}

const NAME_PATTERN = /^[A-Za-z0-9_-]{3,16}$/;
const DIFFICULTY_IDS = ['easy', 'medium', 'hard'];

function readJson(storage, key, fallback) {
  try {
    const raw = storage.getItem(key);
    return raw ? JSON.parse(raw) : fallback;
  } catch {
    return fallback;
  }
}

  try {
    storage.setItem(key, JSON.stringify(value));
    return true;
  } catch {
    return false;
  }
}

const sameName = (a, b) => a.toLowerCase() === b.toLowerCase();

export function validateUsername(input) {
  const name = String(input ?? '').trim();
  if (!NAME_PATTERN.test(name)) {
    return { ok: false, error: 'Use 3 to 16 letters, numbers, _ or -.' };
  }
  return { ok: true, name };
}

function normalizeUser(u) {
  const num = (v) => (Number.isFinite(v) ? v : 0);
  return {
    name: u.name,
    skin: typeof u.skin === 'string' ? u.skin : 'red',
    createdAt: typeof u.createdAt === 'string' ? u.createdAt : '',
    races: num(u.races),
    wins: num(u.wins),
    podiums: num(u.podiums),
    points: num(u.points),
    bestLapMs: Number.isFinite(u.bestLapMs) ? u.bestLapMs : null,
  };
}

export function loadUsers(storage) {
  const parsed = readJson(storage, PROFILES_KEY, []);
  if (!Array.isArray(parsed)) return [];
  return parsed.filter((u) => u && typeof u.name === 'string').map(normalizeUser);
}

export function findUser(storage, name) {
  return loadUsers(storage).find((u) => sameName(u.name, String(name))) ?? null;
}

// Returns { ok: true, user } or { ok: false, error }.
export function registerUser(storage, input, skin = 'red') {
  const checked = validateUsername(input);
  if (!checked.ok) return checked;
  const users = loadUsers(storage);
  if (users.some((u) => sameName(u.name, checked.name))) {
    return { ok: false, error: 'That name is taken. Use Sign in if it is yours.' };
  }
  const user = normalizeUser({ name: checked.name, skin, createdAt: new Date().toISOString() });
  users.push(user);
  if (!writeJson(storage, PROFILES_KEY, users)) {
    return { ok: false, error: 'Could not save (storage is blocked or full).' };
  }
  return { ok: true, user };
}

export function signIn(storage, input) {
  const checked = validateUsername(input);
  if (!checked.ok) return checked;
  const user = findUser(storage, checked.name);
  return user ? { ok: true, user } : { ok: false, error: 'No player with that name. Use Register.' };
}

function updateUser(storage, name, change) {
  const users = loadUsers(storage);
  const user = users.find((u) => sameName(u.name, name));
  if (!user) return null;
  change(user);
  return writeJson(storage, PROFILES_KEY, users) ? user : null;
}

export function setUserSkin(storage, name, skinId) {
  return updateUser(storage, name, (u) => {
    u.skin = skinId;
  });
}

// result: { position, points, bestLapMs }. Returns the updated user, or null if not saved.
export function recordRace(storage, name, { position, points, bestLapMs }) {
  return updateUser(storage, name, (u) => {
    u.races += 1;
    if (position === 1) u.wins += 1;
    if (position <= 3) u.podiums += 1;
    u.points += points;
    if (Number.isFinite(bestLapMs) && (u.bestLapMs === null || bestLapMs < u.bestLapMs)) {
      u.bestLapMs = bestLapMs;
    }
  });
}

function compareUsers(a, b) {
  if (b.points !== a.points) return b.points - a.points;
  if (b.wins !== a.wins) return b.wins - a.wins;
  const lapA = a.bestLapMs ?? Infinity;
  const lapB = b.bestLapMs ?? Infinity;
  if (lapA !== lapB) return lapA - lapB;
  return a.name.localeCompare(b.name);
}

export function leaderboard(storage, limit = 20) {
  return loadUsers(storage).sort(compareUsers).slice(0, limit);
}

function clampInt(value, lo, hi, fallback) {
  const n = Math.round(Number(value));
  return Number.isFinite(n) ? Math.min(hi, Math.max(lo, n)) : fallback;
}

// Race rules: countdown, laps, finishing and standings. Pure logic: no DOM or Three.js imports.

export const POINTS_TABLE = [10, 8, 6, 5, 4, 3, 2, 1];
const COUNTDOWN_SECONDS = 3;

export function pointsFor(position) {
  return POINTS_TABLE[position - 1] ?? 0;
}

export function formatTime(seconds) {
  if (!Number.isFinite(seconds)) return '--:--.---';
  const ms = Math.round(seconds * 1000);
  const minutes = Math.floor(ms / 60000);
  const secs = Math.floor((ms % 60000) / 1000);
  return `${minutes}:${String(secs).padStart(2, '0')}.${String(ms % 1000).padStart(3, '0')}`;
}

export class Race {
  // entrants: [{ name, isPlayer, tracker }]. Race adds lap and finish fields to each entrant.
  constructor({ laps, entrants, trackLength }) {
    this.laps = laps;
    this.trackLength = trackLength;
    this.entrants = entrants;
    this.phase = 'countdown'; // 'countdown' -> 'racing' -> 'finished'
    this.countdown = COUNTDOWN_SECONDS;
    this.time = 0;
    for (const e of entrants) {
      e.lapsDone = 0;
      e.lapStart = 0;
      e.lapTimes = [];
      e.bestLap = null;
      e.finishTime = null;
      e.finished = false;
    }
  }

  // dt is physics time, so slow motion slows the race clock too.
  update(dt) {
    if (this.phase === 'countdown') {
      this.countdown -= dt;
      if (this.countdown <= 0) {
        this.phase = 'racing';
        this.time = 0;
      }
      return;
    }
    if (this.phase !== 'racing') return;

    this.time += dt;
    for (const e of this.entrants) {
      if (e.finished) continue;
      // Cars start behind the line, so lap 1 is complete after the first full circuit.
      const done = Math.min(this.laps, Math.max(0, Math.floor(e.tracker.total / this.trackLength)));
      while (e.lapsDone < done) {
        e.lapsDone += 1;
        const lapTime = this.time - e.lapStart;
        e.lapStart = this.time;
        e.lapTimes.push(lapTime);
        if (e.bestLap === null || lapTime < e.bestLap) e.bestLap = lapTime;
      }
      if (e.lapsDone >= this.laps) {
        e.finished = true;
        e.finishTime = this.time;
      }
    }

    // The race ends when the player finishes; drivers still out there are ranked by distance.
    const player = this.entrants.find((e) => e.isPlayer);
    if (player && player.finished) this.phase = 'finished';
  }

  // Finished drivers first (by finish time), then the rest by distance covered.
  standings() {
    return [...this.entrants].sort((a, b) => {
      if (a.finished !== b.finished) return a.finished ? -1 : 1;
      if (a.finished) return a.finishTime - b.finishTime;
      return b.tracker.total - a.tracker.total;
    });
  }
}

import * as THREE from 'three';

const GRASS_LOW = new THREE.Color(0x2f5d2a);
const GRASS_HIGH = new THREE.Color(0x6b8f3c);
const ROCK = new THREE.Color(0x7b7468);

function smooth(t) {
  const c = Math.min(1, Math.max(0, t));
  return c * c * (3 - 2 * c);
}

// A square grid of terrain centred on the origin, coloured by height and steepness.
export function buildTerrainMesh(world, { size = 2800, cell = 8 } = {}) {
  const segments = Math.round(size / cell);
  const side = segments + 1;
  const half = size / 2;
  const positions = new Float32Array(side * side * 3);
  let minY = Infinity;
  let maxY = -Infinity;

  for (let j = 0; j < side; j++) {
    for (let i = 0; i < side; i++) {
      const x = -half + i * cell;
      const z = -half + j * cell;
      const y = world.terrainHeight(x, z);
      const k = (j * side + i) * 3;
      positions[k] = x;
      positions[k + 1] = y;
      positions[k + 2] = z;
      if (y < minY) minY = y;
      if (y > maxY) maxY = y;
    }
  }

  // Triangles (a, c, b) and (b, c, d) face up.
  const indices = new Uint32Array(segments * segments * 6);
  let n = 0;
  for (let j = 0; j < segments; j++) {
    for (let i = 0; i < segments; i++) {
      const a = j * side + i;
      const b = a + 1;
      const c = a + side;
      const d = c + 1;
      indices[n++] = a;
      indices[n++] = c;
      indices[n++] = b;
      indices[n++] = b;
      indices[n++] = c;
      indices[n++] = d;
    }
  }

  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
  geometry.setIndex(new THREE.BufferAttribute(indices, 1));
  geometry.computeVertexNormals();

  const normals = geometry.getAttribute('normal');
  const colors = new Float32Array(side * side * 3);
  const color = new THREE.Color();
  const range = Math.max(1, maxY - minY);
  for (let v = 0; v < side * side; v++) {
    const height = (positions[v * 3 + 1] - minY) / range;
    color.copy(GRASS_LOW).lerp(GRASS_HIGH, height);
    color.lerp(ROCK, smooth((1 - normals.getY(v) - 0.01) / 0.07));
    colors[v * 3] = color.r;
    colors[v * 3 + 1] = color.g;
    colors[v * 3 + 2] = color.b;
  }
  geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));

  return new THREE.Mesh(
    geometry,
    new THREE.MeshStandardMaterial({ vertexColors: true, roughness: 1, metalness: 0 })
  );
}

// Closed-track builder. Pure logic: no DOM or Three.js imports.
//
// Conventions (XZ plane, Y is up):
// - heading = atan2(tz, tx)
// - right normal = (-tz, tx)
// - curvature > 0 is a right turn, < 0 is a left turn (units: 1/m)

const DENSE_PER_SEGMENT = 64;

function catmullRom(p0, p1, p2, p3, t) {
  const t2 = t * t;
  const t3 = t2 * t;
  return (
    0.5 *
    (2 * p1 +
      (-p0 + p2) * t +
      (2 * p0 - 5 * p1 + 4 * p2 - p3) * t2 +
      (-p0 + 3 * p1 - 3 * p2 + p3) * t3)
  );
}

function wrapAngle(a) {
  while (a > Math.PI) a -= 2 * Math.PI;
  while (a < -Math.PI) a += 2 * Math.PI;
  return a;
}

export function buildTrack(control, options = {}) {
  const { spacing = 2, width = 14, checkpointEvery = 100 } = options;
  const n = control.length;
  if (n < 4) throw new Error('Track needs at least 4 control points');
  if (!(spacing > 0) || !(width > 0) || !(checkpointEvery > 0)) {
    throw new Error('spacing, width and checkpointEvery must be positive');
  }

  // 1. Dense polyline along the closed Catmull-Rom curve.
  const dense = [];
  for (let i = 0; i < n; i++) {
    const p0 = control[(i - 1 + n) % n];
    const p1 = control[i];
    const p2 = control[(i + 1) % n];
    const p3 = control[(i + 2) % n];
    for (let k = 0; k < DENSE_PER_SEGMENT; k++) {
      const t = k / DENSE_PER_SEGMENT;
      dense.push({
        x: catmullRom(p0.x, p1.x, p2.x, p3.x, t),
        y: catmullRom(p0.y ?? 0, p1.y ?? 0, p2.y ?? 0, p3.y ?? 0, t),
        z: catmullRom(p0.z, p1.z, p2.z, p3.z, t),
      });
    }
  }

  // 2. Cumulative length, including the closing segment.
  const m = dense.length;
  const cum = new Array(m + 1);
  cum[0] = 0;
  for (let i = 0; i < m; i++) {
    const a = dense[i];
    const b = dense[(i + 1) % m];
    cum[i + 1] = cum[i] + Math.hypot(b.x - a.x, b.z - a.z);
  }
  const length = cum[m];

  // 3. Resample at equal distances along the curve.
  const count = Math.max(8, Math.round(length / spacing));
  const step = length / count;
  const points = [];
  let seg = 0;
  for (let k = 0; k < count; k++) {
    const s = k * step;
    while (seg < m - 1 && cum[seg + 1] < s) seg++;
    const a = dense[seg];
    const b = dense[(seg + 1) % m];
    const segLen = cum[seg + 1] - cum[seg];
    const f = segLen > 0 ? (s - cum[seg]) / segLen : 0;
    points.push({
      s,
      x: a.x + (b.x - a.x) * f,
      y: a.y + (b.y - a.y) * f,
      z: a.z + (b.z - a.z) * f,
      tx: 0,
      tz: 0,
      nx: 0,
      nz: 0,
      curvature: 0,
      grade: 0,
      width,
    });
  }

  // 4. Tangent, right normal and heading from neighbouring points.
  const heading = new Array(count);
  for (let i = 0; i < count; i++) {
    const prev = points[(i - 1 + count) % count];
    const next = points[(i + 1) % count];
    const dx = next.x - prev.x;
    const dz = next.z - prev.z;
    const len = Math.hypot(dx, dz) || 1;
    const p = points[i];
    p.tx = dx / len;
    p.tz = dz / len;
    p.nx = -p.tz;
    p.nz = p.tx;
    heading[i] = Math.atan2(p.tz, p.tx);
  }

  // 5. Signed curvature = heading change over the distance between neighbours.
  for (let i = 0; i < count; i++) {
    const dTheta = wrapAngle(heading[(i + 1) % count] - heading[(i - 1 + count) % count]);
    points[i].curvature = dTheta / (2 * step);
  }

  // 5b. Grade = rise over horizontal distance, from neighbouring points.
  for (let i = 0; i < count; i++) {
    const prev = points[(i - 1 + count) % count];
    const next = points[(i + 1) % count];
    points[i].grade = (next.y - prev.y) / (2 * step);
  }

  // 6. Checkpoints, roughly every checkpointEvery metres. Index 0 is the start line.
  const cpCount = Math.max(1, Math.round(length / checkpointEvery));
  const checkpoints = [];
  for (let j = 0; j < cpCount; j++) {
    const index = Math.round((j * count) / cpCount) % count;
    const p = points[index];
    checkpoints.push({ index, s: p.s, x: p.x, z: p.z, tx: p.tx, tz: p.tz });
  }

  return { points, length, spacing: step, width, checkpoints };
}

// Track layout: a large closed circuit with hills.
// Control points are { x, y, z } in metres (y is height), listed in driving order.
// The curve is closed automatically (the last point connects back to the first).

const RADIUS_X = 620;
const RADIUS_Z = 380;
const POINT_COUNT = 36;
const MEAN_HEIGHT = 30;

// Road height as a function of the angle around the circuit.
function elevation(angle) {
  return (
    MEAN_HEIGHT +
    14 * Math.sin(angle - 0.6) +
    6 * Math.sin(2 * angle + 1.2) +
    3 * Math.sin(3 * angle)
  );
}

// A wobbly oval: long sweepers with a few tighter bends.
function layout(angle) {
  const wobble = 1 + 0.16 * Math.sin(3 * angle + 0.5) + 0.1 * Math.sin(5 * angle + 1.3);
  return {
    x: RADIUS_X * wobble * Math.cos(angle),
    y: elevation(angle),
    z: RADIUS_Z * wobble * Math.sin(angle),
  };
}

// Starts at the top of the oval, heading east.
export const CONTROL_POINTS = Array.from({ length: POINT_COUNT }, (_, i) =>
  layout(-Math.PI / 2 + (i / POINT_COUNT) * Math.PI * 2)
);

export const TRACK_OPTIONS = {
  spacing: 3, // metres between sampled points
  width: 16, // road width in metres
  checkpointEvery: 150, // approximate metres between checkpoints
};

function smoothstep(edge0, edge1, x) {
  const t = Math.min(1, Math.max(0, (x - edge0) / (edge1 - edge0)));
  return t * t * (3 - 2 * t);
}

// Natural ground height away from the road. Around the circuit it follows the same
// elevation as the road, so the terrain near the road is already close to road height.
export function baseHeight(x, z) {
  const nx = x / RADIUS_X;
  const nz = z / RADIUS_Z;
  const rho = Math.hypot(nx, nz); // about 1 on the circuit, 0 at the middle
  const angle = Math.atan2(nz, nx);
  // The angle is meaningless near the middle, so the hills fade out there and far outside.
  const hills =
    (elevation(angle) - MEAN_HEIGHT) *
    smoothstep(0.1, 0.5, rho) *
    (1 - 0.7 * smoothstep(1.4, 2.4, rho));
  const rolling = 5 * Math.sin(x / 230) * Math.cos(z / 190) + 3 * Math.sin((x - z) / 140);
  return MEAN_HEIGHT + hills + rolling;
}

import * as THREE from 'three';
import { WALL_GAP, WALL_HEIGHT } from './world.js';

const START_LINE_LIFT = 0.03;
const DEBUG_LIFT = 0.1;

function geometryFromPoints(pts) {
  const g = new THREE.BufferGeometry();
  g.setFromPoints(pts);
  return g;
}

// Vertex 2i is the right edge (or wall bottom), vertex 2i+1 the left edge (or wall top).
// Triangles (2i, 2j, 2i+1) and (2i+1, 2j, 2j+1) face up for the road.
function buildStrip(positions, count) {
  const indices = [];
  for (let i = 0; i < count; i++) {
    const j = (i + 1) % count;
    indices.push(2 * i, 2 * j, 2 * i + 1, 2 * i + 1, 2 * j, 2 * j + 1);
  }
  const geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));
  geo.setIndex(indices);
  geo.computeVertexNormals();
  return geo;
}

function buildRoad(track) {
  const { points, width } = track;
  const hw = width / 2;
  const n = points.length;
  const positions = new Float32Array(n * 6);
  for (let i = 0; i < n; i++) {
    const p = points[i];
    positions.set([p.x + p.nx * hw, p.y, p.z + p.nz * hw], i * 6);
    positions.set([p.x - p.nx * hw, p.y, p.z - p.nz * hw], i * 6 + 3);
  }
  return new THREE.Mesh(
    buildStrip(positions, n),
    new THREE.MeshStandardMaterial({ color: 0x555b66 })
  );
}

// side = +1 for the right wall, -1 for the left wall.
function buildWall(track, side) {
  const { points, width } = track;
  const offset = side * (width / 2 + WALL_GAP);
  const n = points.length;
  const positions = new Float32Array(n * 6);
  for (let i = 0; i < n; i++) {
    const p = points[i];
    const x = p.x + p.nx * offset;
    const z = p.z + p.nz * offset;
    positions.set([x, p.y, z], i * 6);
    positions.set([x, p.y + WALL_HEIGHT, z], i * 6 + 3);
  }
  return new THREE.Mesh(
    buildStrip(positions, n),
    new THREE.MeshStandardMaterial({ color: 0xb0453a, side: THREE.DoubleSide })
  );
}

function buildStartLine(track) {
  const p = track.points[0];
  const hw = track.width / 2;
  const corner = (side, along) =>
    new THREE.Vector3(
      p.x + p.nx * hw * side + p.tx * along,
      p.y + p.grade * along + START_LINE_LIFT,
      p.z + p.nz * hw * side + p.tz * along
    );
  const rightBack = corner(1, -1);
  const rightFront = corner(1, 1);
  const leftBack = corner(-1, -1);
  const leftFront = corner(-1, 1);

  return new THREE.Mesh(
    geometryFromPoints([rightBack, rightFront, leftBack, leftBack, rightFront, leftFront]),
    new THREE.MeshBasicMaterial({
      color: 0xffffff,
      side: THREE.DoubleSide,
      polygonOffset: true,
      polygonOffsetFactor: -1,
      polygonOffsetUnits: -1,
    })
  );
}

export function buildTrackMesh(track) {
  const group = new THREE.Group();
  group.add(buildRoad(track));
  group.add(buildWall(track, 1));
  group.add(buildWall(track, -1));
  group.add(buildStartLine(track));
  return group;
}

// Follows a car along the track: distance along the circuit, laps, and distance from the road.
// Pure logic: no DOM or Three.js imports.

const WINDOW = 20; // track points searched on each side of the last known position
const MAX_OFFSET = 22; // metres from the centre line; farther away, progress stops counting

export class TrackTracker {
  constructor(track) {
    this.track = track;
    this.index = 0; // nearest track point
    this.s = 0; // distance along the lap, 0..length
    this.lap = 0;
    this.total = 0; // lap * length + s; negative behind the start line
    this.dist = 0; // distance from the centre line
    this.offTrack = false;
  }

  // Places the tracker at a total distance (negative = behind the start line).
  setProgress(total) {
    const { length, points, spacing } = this.track;
    this.lap = Math.floor(total / length);
    this.s = total - this.lap * length;
    this.index = Math.round(this.s / spacing) % points.length;
    this.total = total;
    this.dist = 0;
    this.offTrack = false;
  }

  update(x, z) {
    const { points, length, spacing } = this.track;
    const n = points.length;

    let best = this.index;
    let bestD2 = Infinity;
    for (let k = -WINDOW; k <= WINDOW; k++) {
      const i = (this.index + k + n) % n;
      const dx = points[i].x - x;
      const dz = points[i].z - z;
      const d2 = dx * dx + dz * dz;
      if (d2 < bestD2) {
        bestD2 = d2;
        best = i;
      }
    }
    this.dist = Math.sqrt(bestD2);
    this.offTrack = this.dist > MAX_OFFSET;
    if (this.offTrack) return; // too far from the road: keep the last progress

    // Fraction along the segment from point a to point b.
    const fraction = (a, b) => {
      const pa = points[a];
      const pb = points[b];
      const sx = pb.x - pa.x;
      const sz = pb.z - pa.z;
      const len2 = sx * sx + sz * sz;
      return len2 > 0 ? ((x - pa.x) * sx + (z - pa.z) * sz) / len2 : 0;
    };
    let segment = best;
    let t = fraction(best, (best + 1) % n);
    if (t < 0) {
      segment = (best - 1 + n) % n;
      t = fraction(segment, best);
    }
    t = Math.min(1, Math.max(0, t));
    const s = Math.min(length, (segment + t) * spacing);

    // Crossing the start line wraps s between about 0 and length.
    const delta = s - this.s;
    if (delta < -length / 2) this.lap += 1;
    else if (delta > length / 2) this.lap -= 1;

    this.s = s;
    this.index = best;
    this.total = this.lap * length + s;
  }
}

// Ground height, surface grip and wall queries for the road and the terrain around it.
// Pure logic: no DOM or Three.js imports.

export const WALL_GAP = 0.3; // m between the road edge and the wall
export const WALL_HEIGHT = 1.2; // m

const SHOULDER = 14; // m of flat ground beside the road edge
const BLEND = 50; // m over which the terrain eases from road height to its natural height
const ROAD_DEPTH = 0.1; // terrain sits this far under the road so the road mesh never flickers
const LIP = 1.5; // m over which the driving surface drops to the terrain at the road edge
const SURFACE_FADE = 1.5; // m over which tarmac turns into grass at the road edge
const GRASS_GRIP = 0.55; // tire grip on grass compared with tarmac
const GRASS_DRAG = 4; // rolling resistance on grass compared with tarmac

function smoothstep01(t) {
  const c = Math.min(1, Math.max(0, t));
  return c * c * (3 - 2 * c);
}

// Closest point to (x, z) on the segment a-b, as { dist, y, offset, nx, nz }.
// offset is the signed distance across the segment (positive to the right of the direction of
// travel) and (nx, nz) is the segment's right-hand unit normal.
function closestOnSegment(a, b, x, z) {
  const dx = b.x - a.x;
  const dz = b.z - a.z;
  const len2 = dx * dx + dz * dz;
  let t = len2 > 0 ? ((x - a.x) * dx + (z - a.z) * dz) / len2 : 0;
  t = Math.min(1, Math.max(0, t));
  const px = a.x + dx * t;
  const pz = a.z + dz * t;
  const len = Math.sqrt(len2) || 1;
  const nx = -dz / len;
  const nz = dx / len;
  return {
    dist: Math.hypot(x - px, z - pz),
    y: a.y + (b.y - a.y) * t,
    offset: (x - px) * nx + (z - pz) * nz,
    nx,
    nz,
  };
}

// baseHeight(x, z) is the natural ground height away from the road.
export function createWorld(track, baseHeight = () => 0) {
  const { points } = track;
  const n = points.length;
  const half = track.width / 2;
  const flatEdge = half + SHOULDER;
  const reach = flatEdge + BLEND;
  const cell = reach; // the 3x3 block of cells around a query covers every point within `reach`
  const cellKey = (cx, cz) => (cx + 4096) * 8192 + (cz + 4096);

  const grid = new Map();
  for (let i = 0; i < n; i++) {
    const key = cellKey(Math.floor(points[i].x / cell), Math.floor(points[i].z / cell));
    const list = grid.get(key);
    if (list) list.push(i);
    else grid.set(key, [i]);
  }

  // Closest point on the centre line, or null if the road is farther than `reach`.
  function nearest(x, z) {
    const cx = Math.floor(x / cell);
    const cz = Math.floor(z / cell);
    let best = -1;
    let bestD2 = Infinity;
    for (let dx = -1; dx <= 1; dx++) {
      for (let dz = -1; dz <= 1; dz++) {
        const list = grid.get(cellKey(cx + dx, cz + dz));
        if (!list) continue;
        for (const i of list) {
          const p = points[i];
          const d2 = (p.x - x) * (p.x - x) + (p.z - z) * (p.z - z);
          if (d2 < bestD2) {
            bestD2 = d2;
            best = i;
          }
        }
      }
    }
    if (best < 0) return null;

    // Project onto the two segments next to the nearest point, so heights are exact on slopes.
    const p = points[best];
    const s1 = closestOnSegment(points[(best - 1 + n) % n], p, x, z);
    const s2 = closestOnSegment(p, points[(best + 1) % n], x, z);
    const hit = s1.dist < s2.dist ? s1 : s2;
    return hit.dist <= reach ? hit : null;
  }

  function height(x, z, withLip, hit) {
    const base = baseHeight(x, z);
    if (!hit) return base;
    const roadLevel = hit.y - ROAD_DEPTH;
    const t = smoothstep01((hit.dist - flatEdge) / BLEND);
    let h = roadLevel + (base - roadLevel) * t;
    if (withLip) h += ROAD_DEPTH * (1 - smoothstep01((hit.dist - half) / LIP));
    return h;
  }

  // Everything the car physics needs about one spot: driving height and the surface under it.
  function sample(x, z) {
    const hit = nearest(x, z);
    const grass = hit ? smoothstep01((hit.dist - half) / SURFACE_FADE) : 1; // 0 on the road, 1 on grass
    return {
      height: height(x, z, true, hit),
      grip: 1 + (GRASS_GRIP - 1) * grass,
      drag: 1 + (GRASS_DRAG - 1) * grass,
    };
  }

  return {
    // Height of the surface a car drives on: the road itself, or the terrain.
    groundHeight: (x, z) => height(x, z, true, nearest(x, z)),
    // Height of the terrain mesh (0.1 m under the road).
    terrainHeight: (x, z) => height(x, z, false, nearest(x, z)),
    sample,
    // Signed distance from the centre line (positive = right) and the right-hand normal, or null.
    lateral(x, z) {
      const hit = nearest(x, z);
      return hit ? { offset: hit.offset, nx: hit.nx, nz: hit.nz } : null;
    },
    wallOffset: half + WALL_GAP, // distance from the centre line to the inner face of the walls
    nearest,
  };
}

import { test } from 'node:test';
import assert from 'node:assert/strict';
import { buildTrack } from '../src/track/track.js';
import { CONTROL_POINTS, TRACK_OPTIONS, baseHeight } from '../src/track/trackData.js';
import { createWorld } from '../src/track/world.js';
import { TrackTracker } from '../src/track/tracker.js';
import { Vehicle } from '../src/physics/vehicle.js';
import { readCarSpec } from '../src/physics/spec.js';
import { BotDriver } from '../src/ai/bot.js';
import { resetAll, setParam } from '../src/config/registry.js';

const DT = 1 / 120;
const track = buildTrack(CONTROL_POINTS, TRACK_OPTIONS);
const world = createWorld(track, baseHeight);

// Drives one lap from a standing start on the line.
function driveLap(friction, difficulty = 'medium') {
  resetAll();
  setParam('tire.friction', friction);
  const start = track.points[0];
  const car = new Vehicle({ x: start.x, z: start.z, yaw: Math.atan2(start.tz, start.tx), ground: world });
  const tracker = new TrackTracker(track);
  tracker.setProgress(0);
  const driver = new BotDriver({ difficulty });

  let time = 0;
  let maxOffset = 0;
  while (tracker.total < track.length && time < 500) {
    car.step(DT, driver.drive(car, tracker, readCarSpec()));
    tracker.update(car.x, car.z);
    maxOffset = Math.max(maxOffset, tracker.dist);
    time += DT;
  }
  resetAll();
  return { finished: tracker.total >= track.length, time, maxOffset, recoveries: car.recoveries };
}

for (const [difficulty, friction] of [
  ['easy', 1.0],
  ['medium', 1.0],
  ['hard', 1.0],
  ['medium', 0.5],
  ['medium', 1.5],
]) {
  test(`a ${difficulty} bot completes a lap and stays on the road with friction ${friction}`, () => {
    const r = driveLap(friction, difficulty);
    assert.ok(r.finished, `did not finish a lap in ${r.time.toFixed(0)} s`);
    assert.ok(r.maxOffset < 14, `strayed ${r.maxOffset.toFixed(1)} m from the centre line`);
    assert.equal(r.recoveries, 0);
  });
}

function circle(radius, count) {
  const pts = [];
  for (let i = 0; i < count; i++) {
    const a = (i / count) * Math.PI * 2;
    pts.push({ x: radius * Math.cos(a), z: radius * Math.sin(a) });
  }
  return pts;
}

// The track point at a distance along the lap (wraps around).
function at(s) {
  const m = ((s % track.length) + track.length) % track.length;
  return track.points[Math.round(m / track.spacing) % track.points.length];
}

test('driving a lap from behind the line adds up to the lap length', () => {
  const t = new TrackTracker(track);
  t.setProgress(-12);
  assert.equal(t.lap, -1);
  for (let s = -12; s <= track.length + 12; s += 2) {
    const p = at(s);
    t.update(p.x, p.z);
    assert.ok(Math.abs(t.total - s) < 3, `at ${s} the tracker says ${t.total}`);
  }
  assert.equal(t.lap, 1);
});

test('driving backwards over the line takes a lap off', () => {
  const t = new TrackTracker(track);
  t.setProgress(10);
  for (let s = 10; s >= -10; s -= 2) {
    const p = at(s);
    t.update(p.x, p.z);
  }
  assert.equal(t.lap, -1);
  assert.ok(Math.abs(t.total + 10) < 3);
});

test('progress stops counting when far from the road and resumes on return', () => {
  const t = new TrackTracker(track);
  t.setProgress(500);
  const p = at(500);
  t.update(p.x, p.z);
  const before = t.total;
  t.update(p.x + p.nx * 60, p.z + p.nz * 60);
  assert.equal(t.offTrack, true);
  assert.equal(t.total, before);

  assert.equal(world.lateral(1e5, 1e5), null);
});
